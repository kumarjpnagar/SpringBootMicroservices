🔷 4️⃣ GitHub Actions CI Pipeline
Create:

.github/workflows/ci.yml

name: CI Pipeline

on:
  push:
    branches:
      - main

jobs:
  build:
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v3

      - name: Set up Java
        uses: actions/setup-java@v3
        with:
          distribution: 'temurin'
          java-version: '17'

      - name: Build Project
        run: mvn clean package

      - name: Run SonarQube
        run: mvn sonar:sonar

      - name: Login to DockerHub
        run: echo ${{ secrets.DOCKER_PASSWORD }} | docker login -u ${{ secrets.DOCKER_USERNAME }} --password-stdin

      - name: Build Docker Image
        run: docker build -t yourdockerhub/demo:${{ github.sha }} .

      - name: Push Image
        run: docker push yourdockerhub/demo:${{ github.sha }}

🔷 2️⃣ Full Production-Level Harness Canary Pipeline YAML

pipeline:
  name: gke-canary-full
  identifier: gke_canary_full
  projectIdentifier: demo_project
  orgIdentifier: default
  stages:

    - stage:
        name: Canary_Deployment
        identifier: canary_stage
        type: Deployment
        spec:
          deploymentType: Kubernetes
          service:
            serviceRef: demo_service
          environment:
            environmentRef: staging_env
            deployToAll: false

          execution:
            steps:

              #################################################
              # 1️⃣ INITIALIZE
              #################################################
              - step:
                  type: K8sCanaryDeploy
                  name: initialize
                  identifier: initialize
                  spec:
                    instanceSelection:
                      type: Count
                      spec:
                        count: 1

              #################################################
              # 2️⃣ RUNTIME INPUTS (Optional Shell Validation)
              #################################################
              - step:
                  type: ShellScript
                  name: rc_inputs
                  identifier: rc_inputs
                  spec:
                    shell: Bash
                    source:
                      type: Inline
                      spec:
                        script: |
                          echo "Validating runtime inputs..."
                          echo "Artifact Tag: <+artifact.tag>"
                    environmentVariables: []

              #################################################
              # 3️⃣ DEPLOY STABLE VERSION
              #################################################
              - step:
                  type: K8sRollingDeploy
                  name: deploy
                  identifier: deploy
                  spec:
                    skipDryRun: false

              #################################################
              # 4️⃣ CANARY DEPLOY (10%)
              #################################################
              - step:
                  type: K8sCanaryDeploy
                  name: canary
                  identifier: canary
                  spec:
                    instanceSelection:
                      type: Percentage
                      spec:
                        percentage: 10

              #################################################
              # 5️⃣ ROUTE TRAFFIC (If using Istio)
              #################################################
              - step:
                  type: K8sTrafficShift
                  name: route_traffic
                  identifier: route_traffic
                  spec:
                    trafficSplit:
                      percentage: 10

              #################################################
              # 6️⃣ VERIFY (Prometheus Monitoring)
              #################################################
              - step:
                  type: Verify
                  name: verify
                  identifier: verify
                  spec:
                    type: Prometheus
                    spec:
                      monitoringTool: prometheus_connector
                      sensitivity: MEDIUM
                      duration: 5m

              #################################################
              # 7️⃣ CONDITIONAL POST DEPLOY
              #################################################
              - step:
                  type: HarnessApproval
                  name: conditional_post_deploy
                  identifier: conditional_post_deploy
                  spec:
                    approvalMessage: "Approve promotion to 100%?"
                    includePipelineExecutionHistory: true
                    approvers:
                      userGroups:
                        - account._account_all_users
                      minimumCount: 1

              #################################################
              # 8️⃣ PROMOTE TO 100%
              #################################################
              - step:
                  type: K8sCanaryDelete
                  name: promote
                  identifier: promote

              #################################################
              # 9️⃣ CLEANUP OLD VERSION
              #################################################
              - step:
                  type: K8sRollingRollback
                  name: cleanup
                  identifier: cleanup
                  when:
                    stageStatus: Failure

              #################################################
              # 🔟 AUTOMATION (Slack Notification)
              #################################################
              - step:

  order-service:1.0

🔥 4️⃣ Docker Networking Deep Explanation

✔When Docker installs, it creates:

docker network ls
Default network:

bridge
host
none

🔹 Bridge Network (Default)
Containers get private IPs:

172.17.0.2
172.17.0.3
They communicate using:

IP

Container name (if custom network)

Example:

docker network create app-net
Containers on app-net can talk via:

http://order-service:8080
🔹 Host Network
Container shares host IP.

docker run --network host nginx

No port mapping needed.

🔹 None Network
No networking.

docker run --network none nginx
Used for high security.

🔹 Overlay Network (Swarm / Multi-host)

🔥 5️⃣ Multi-Stage Dockerfile (Production Optimized)
Problem:

Normal Docker image size = 800MB ❌
Multi-stage reduces to = 120MB ✅

❌ Normal Dockerfile
FROM maven:3.9.0-jdk-17

WORKDIR /app
COPY . .
RUN mvn clean package

CMD ["java","-jar","target/demo.jar"]
Large image ❌

✅ Multi-Stage Dockerfile
# Stage 1 - Build
FROM maven:3.9.0-jdk-17 AS build

WORKDIR /app
COPY pom.xml .
COPY src ./src

RUN mvn clean package -DskipTests

# Stage 2 - Runtime
FROM eclipse-temurin:17-jre-alpine

WORKDIR /app
COPY --from=build /app/target/demo.jar app.jar

EXPOSE 8080

ENTRYPOINT ["java","-jar","app.jar"]
How Multi-Stage Works
Stage 1 → Build jar
Stage 2 → Copy only jar
Final Image → No Maven, No Source Code
Smaller, secure, production-ready.

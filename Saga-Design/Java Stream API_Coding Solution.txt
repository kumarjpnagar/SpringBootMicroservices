import java.util.*;
import java.util.stream.*;

public class EvenIntegerList {
    public static void main(String[] args) {

        List<String> input = Arrays.asList("1","2","3","4","abc","5");

        List<Integer> evenNumbers =
                input.stream()
                        // Step 1: Filter numeric values
                        .filter(s -> s.matches("\\d+"))
                        // Step 2: Convert to Integer
                        .map(Integer::parseInt)
                        // Step 3: Filter even numbers
                        .filter(n -> n % 2 == 0)
                        // Step 4: Collect result
                        .collect(Collectors.toList());

        System.out.println(evenNumbers);
    }
}

Find second non-repeated character using streams

Finding the second non-repeated character using Java Streams is a very common interview question.
The idea is:

1️⃣ Convert the string → stream of characters
2️⃣ Count frequency of each character
3️⃣ Preserve insertion order (important)
4️⃣ Filter characters with frequency = 1
5️⃣ Skip first → take second

We use LinkedHashMap to preserve the order.

Example
Input

String str = "javaarticles";
Characters and frequency

Character	Count
j	1
a	3
v	1
r	1
t	1
i	1
c	1
l	1
e	1
s	1

Non-repeated characters

j, v, r, t, i, c, l, e, s
Second non-repeated

v
Complete Java Stream Solution
import java.util.*;
import java.util.function.Function;
import java.util.stream.Collectors;

public class SecondNonRepeated {

    public static void main(String[] args) {

        String str = "javaarticles";

        Character result =
                str.chars()
                   .mapToObj(c -> (char) c)
                   .collect(Collectors.groupingBy(
                           Function.identity(),
                           LinkedHashMap::new,
                           Collectors.counting()
                   ))
                   .entrySet()
                   .stream()
                   .filter(e -> e.getValue() == 1)
                   .skip(1)
                   .map(Map.Entry::getKey)
                   .findFirst()
                   .orElse(null);

        System.out.println(result);
    }

Shallow copy and Deep copy hands on? 


🧠 1. Concept First (Simple)

✅ Shallow Copy

Copies object reference

Both objects point to same nested object

Change in one → affects the other

👉 Think: “copy of address, not actual house”

✅ Deep Copy

Copies entire object including nested objects

Objects are completely independent

👉 Think: “duplicate house built separately”

🏗️ Example Model

    }
}

class Person {
    String name;
    Address address;

    Person(String name, Address address) {
        this.name = name;
        this.address = address;
    }

🔥 3. Deep Copy (Hands-on)

💻 Complete Program
class Address {
    String city;

    Address(String city) {
        this.city = city;
    }
}

class Person implements Cloneable {
    String name;
    Address address;

    Person(String name, Address address) {
        this.name = name;
        this.address = address;
    }

    protected Object clone() throws CloneNotSupportedException {

        Person cloned = (Person) super.clone();

        // Deep copy of Address
        cloned.address = new Address(this.address.city);

        return cloned;
    }
}

public class DeepCopyDemo {
    public static void main(String[] args) throws Exception {

        Address addr = new Address("Bangalore");

        Person p1 = new Person("Rakesh", addr);

        // Deep copy

    public static boolean areAnagramsUsingStreams(String str1, String str2) {
        String s1 = str1.replaceAll("\\s", "").toLowerCase();
        String s2 = str2.replaceAll("\\s", "").toLowerCase();
        
        if (s1.length() != s2.length()) return false;

        return sortString(s1).equals(sortString(s2));
    }

    private static String sortString(String str) {
        // Creates sorted character stream
        return str.chars()
                  .sorted()
                  .collect(StringBuilder::new, StringBuilder::appendCodePoint, StringBuilder::append)
                  .toString();
    }
}

import java.util.List;
import java.util.Objects;

public class DuplicateDetector {

    /**
     * Returns true if the input list contains any duplicate vulnerability
     * (same title AND same severityScore), otherwise false.
     */
    public static boolean hasDuplicates(List<Vulnerability> items) {
        if (items == null || items.size() <= 1) {
            return false;
        }

        // Compare total count to distinct count using equals/hashCode
        long distinctCount = items.stream()
                                  .distinct()
                                  .count();

        return distinctCount < items.size();
    }
}

class Vulnerability {
    private final String title;        // e.g., "SQL Injection"
    private final double severityScore; // e.g., 9.8

    public Vulnerability(String title, double severityScore) {
        this.title = title;
        this.severityScore = severityScore;
    }

    // Required for distinct() to work properly on title AND severityScore
    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Vulnerability that = (Vulnerability) o;
        return Double.compare(that.severityScore, severityScore) == 0 &&
               Objects.equals(title, that.title);
    }

    @Override
    public int hashCode() {
        return Objects.hash(title, severityScore);
    }
}

import java.util.*;
import java.util.stream.*;
import java.util.function.Function;

public class AnagramCounter {
    public static void main(String[] args) {
        String input = "abc cab bac abcd def cdba";

        Map<String, Long> result = Arrays.stream(input.split(" "))
            .collect(Collectors.groupingBy(word -> {
                // Sort characters of the word to create a unique key for anagrams
                char[] chars = word.toCharArray();
                Arrays.sort(chars);
                return new String(chars);
            }, Collectors.counting()));

        // Display results in the required format
        String output = result.entrySet().stream()
            .map(e -> e.getKey() + " - " + e.getValue())
            .collect(Collectors.joining(" , "));

        System.out.println(output);
    }
}

Explanation of Steps:

Splitting the Input: The String.split(" ") method converts the space-separated string into an array of individual words.

Generating Anagram Keys: For each word, the characters are converted to a char[] and sorted using Arrays.sort(). Words like "abc", "cab", and "bac" all result in the same key: "abc".

Grouping and Counting: The Collectors.groupingBy method organizes the words by these sorted keys, while Collectors.counting() calculates the frequency of each group.

Formatting Output: The final map is streamed to join the keys and values into the desired string format

import com.google.common.util.concurrent.RateLimiter;

public class GuavaExample {
    public static void main(String[] args) {
        // Allow 2.0 requests per second
        RateLimiter limiter = RateLimiter.create(2.0);

        for (int i = 0; i < 5; i++) {
            // acquire() blocks until a permit is available
            double waitTime = limiter.acquire();
            System.out.println("Acquired permit after " + waitTime + "s");
            processRequest(i);
        }
    }

    private static void processRequest(int i) {
        System.out.println("Processing request: " + i);
    }
}

Rate Limiter Implementation (Sliding Window Log)

import java.time.Instant;
import java.util.Collections;
import java.util.List;
import java.util.stream.Collectors;

public class StreamRateLimiter {
    private final int maxRequests;
    private final long windowInSeconds;

    public StreamRateLimiter(int maxRequests, long windowInSeconds) {
        this.maxRequests = maxRequests;
        this.windowInSeconds = windowInSeconds;
    }

    /**
     * Filters a list of request timestamps to identify those within the rate limit.
     * @param requestTimestamps History of request Epoch seconds.
     * @return List of allowed request timestamps within the current window.
     */
    public List<Long> getAllowedRequests(List<Long> requestTimestamps) {
        long currentTime = Instant.now().getEpochSecond();
        long windowStart = currentTime - windowInSeconds;

        return requestTimestamps.stream()
            // Step 1: Remove expired logs outside the current window
            .filter(timestamp -> timestamp > windowStart)
            // Step 2: Limit to the maximum allowed requests
            .limit(maxRequests)
            .collect(Collectors.toList());
    }
}

1. Bucket4j (Token Bucket Algorithm)
Bucket4j is a popular Java library for local and distributed rate limiting. It works by assigning "tokens" to a bucket; each request consumes a token

Dependency (Maven): Add the Bucket4j Spring Boot Starter to your pom.xml.
Java Service Example:

@Service
public class RateLimiterService {
    private final Map<String, Bucket> buckets = new ConcurrentHashMap<>();

    public Bucket resolveBucket(String apiKey) {
        return buckets.computeIfAbsent(apiKey, key -> Bucket.builder()
            .addLimit(Bandwidth.classic(10, Refill.greedy(10, Duration.ofMinutes(1))))
            .build());
    }
}

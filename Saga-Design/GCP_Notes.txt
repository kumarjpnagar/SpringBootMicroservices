Run stateless HTTP services

package com.example;

import com.google.cloud.functions.HttpFunction;
import com.google.cloud.functions.HttpRequest;
import com.google.cloud.functions.HttpResponse;

import java.io.BufferedWriter;

public class HelloHttpFunction implements HttpFunction {

    @Override
    public void service(HttpRequest request, HttpResponse response) throws Exception {

        String name = request.getFirstQueryParameter("name").orElse("World");

        BufferedWriter writer = response.getWriter();

    }
}

/**

Object Lifecycle:

☁️ Google Cloud Storage (Hands-on): Object Lifecycle
Google Cloud Storage provides Object Lifecycle Management to automatically manage objects in a bucket based on conditions such as age, storage class, or version.

This feature helps:

Reduce storage cost 💰

Automatically delete old files

Move objects to cheaper storage classes

All lifecycle rules are configured on a bucket in Google Cloud Platform.

1️⃣ What is Object Lifecycle?
Object lifecycle means automatically performing actions on objects when certain conditions are met.

Example:

If file age > 30 days → Move to Nearline storage
If file age > 365 days → Delete object
So instead of manually managing files, Cloud Storage automatically handles it.

2️⃣ Lifecycle Architecture
Bucket
 │
 ├── image1.jpg (5 days)
 ├── image2.jpg (40 days)
 └── image3.jpg (400 days)
Lifecycle rules:

Age > 30 days → Change storage class
Age > 365 days → Delete object
Result:

image1.jpg → Standard
image2.jpg → Nearline
image3.jpg → Deleted
3️⃣ Lifecycle Rule Components
Lifecycle rules contain two parts:

Part	Purpose
Action	What to do
Condition	When to do it
Example rule:

Condition → age = 30 days
Action → change storage class to Nearline
4️⃣ Supported Lifecycle Actions
Action	Description
Delete	Remove object
SetStorageClass	Change storage class
Example:

Standard → Nearline → Coldline → Archive
5️⃣ Supported Lifecycle Conditions
Condition	Meaning
age	object age in days
createdBefore	object created before date
matchesStorageClass	current storage class
numNewerVersions	number of newer versions
isLive	live object
Example:

Delete objects older than 365 days

8️⃣ Example Rule for Deleting Objects
Example:

Condition:

Action:
Delete
Meaning:

Files older than 1 year
→ automatically deleted
9️⃣ Lifecycle JSON Configuration
Lifecycle rules are stored as JSON configuration.

☁️ Google Cloud Storage (Hands-on): Signed URL
A Signed URL allows temporary secure access to a private object in Google Cloud Storage without making the object public.

It is commonly used when an application needs to allow temporary download or upload access.

Example use cases:

User downloads a private file
User uploads a file directly from browser
Temporary access to private media

1️⃣ What is a Signed URL?
A Signed URL is a URL that includes a cryptographic signature and expiration time.

Signed URL = Resource URL + Signature + Expiration
Example:

https://storage.googleapis.com/my-bucket/report.pdf
?X-Goog-Algorithm=GOOG4-RSA-SHA256
&X-Goog-Credential=service-account
&X-Goog-Date=20260308T100000Z
&X-Goog-Expires=900
&X-Goog-SignedHeaders=host
&X-Goog-Signature=abc123xyz...
Meaning:

File: report.pdf
Access: allowed
Duration: 15 minutes
Authentication: signature

5️⃣ Generate Signed URL Using Java (Spring Boot Example)
Dependencies:

<dependency>
  <groupId>com.google.cloud</groupId>
  <artifactId>google-cloud-storage</artifactId>
</dependency>
Java Code Example
import com.google.cloud.storage.BlobInfo;
import com.google.cloud.storage.Storage;
import com.google.cloud.storage.StorageOptions;
import java.net.URL;
import java.util.concurrent.TimeUnit;

public class SignedUrlExample {

    public static void main(String[] args) {

        String bucketName = "signed-url-demo-bucket";
        String objectName = "report.pdf";

        // Create storage client
        Storage storage = StorageOptions.getDefaultInstance().getService();

        BlobInfo blobInfo = BlobInfo.newBuilder(bucketName, objectName).build();

        // Generate signed URL valid for 15 minutes
        URL url = storage.signUrl(
                blobInfo,
                15,
                TimeUnit.MINUTES,
                Storage.SignUrlOption.withV4Signature()
        );

        System.out.println("Signed URL: " + url);
    }
}
Explanation:

Storage client → connects to GCP
BlobInfo → defines file
signUrl() → generates temporary access link

4️⃣ Simple Apache Beam Pipeline Example
Java example:

import org.apache.beam.sdk.Pipeline;
import org.apache.beam.sdk.transforms.Create;
import org.apache.beam.sdk.transforms.MapElements;
import org.apache.beam.sdk.values.TypeDescriptors;

public class DataflowExample {

    public static void main(String[] args) {

        Pipeline pipeline = Pipeline.create();

        pipeline
            .apply(Create.of("apple", "banana", "cherry"))
            .apply(MapElements.into(TypeDescriptors.strings())
                    .via(word -> word.toUpperCase()))
            .apply(org.apache.beam.sdk.io.TextIO.write()
                    .to("output.txt"));

        pipeline.run().waitUntilFinish();
    }
}
Explanation:

Pipeline → data processing pipeline
Create.of() → input data
MapElements → transform data
TextIO.write() → output

7️⃣ Java Example (Publisher)
Dependency:

<dependency>
 <groupId>com.google.cloud</groupId>
 <artifactId>google-cloud-pubsub</artifactId>
</dependency>
Publisher code:

import com.google.cloud.pubsub.v1.Publisher;
import com.google.pubsub.v1.ProjectTopicName;
import com.google.pubsub.v1.PubsubMessage;
import com.google.protobuf.ByteString;

public class PubSubPublisher {

    public static void main(String[] args) throws Exception {

        String projectId = "my-project";
        String topicId = "order-events";

        ProjectTopicName topicName =
                ProjectTopicName.of(projectId, topicId);

        Publisher publisher = Publisher.newBuilder(topicName).build();

        String message = "New Order Created";

        PubsubMessage pubsubMessage =
                PubsubMessage.newBuilder()
                        .setData(ByteString.copyFromUtf8(message))
                        .build();

        publisher.publish(pubsubMessage).get();

        System.out.println("Message published");

        publisher.shutdown();
    }
}
Explanation:

Publisher → sends message
Topic → receives message
PubsubMessage → message payload

8️⃣ Java Example (Subscriber)
Subscriber code:

import com.google.cloud.pubsub.v1.Subscriber;
import com.google.pubsub.v1.ProjectSubscriptionName;

public class PubSubSubscriber {

    public static void main(String[] args) {

        String projectId = "my-project";
        String subscriptionId = "order-processor-sub";

        ProjectSubscriptionName subscriptionName =
                ProjectSubscriptionName.of(projectId, subscriptionId);

        Subscriber subscriber =
                Subscriber.newBuilder(subscriptionName,
                        (message, consumer) -> {

                            System.out.println(
                                    "Received: " +
                                    message.getData().toStringUtf8());

                            consumer.ack();
                        }).build();

        subscriber.startAsync().awaitRunning();
    }
}
Explanation:

Subscriber → receives message
ack() → confirms message processing

Identity and Access Management in Google Cloud Platform allows you to control who (users or services) can access what resources and what actions they can perform.

Resource (where) → Project / Service / Resource

Role: Viewer
Resource: Project

🧪 1️⃣ Managing Service Accounts with Limited Privileges

Click:

Create Service Account

Step 3: Assign Limited Role
Choose a restricted role.

Example:

List storage objects

CLI Method
Using Google Cloud SDK

Create service account:

gcloud iam service-accounts create limited-storage-sa \

gcloud projects add-iam-policy-binding PROJECT_ID \
--member="serviceAccount:limited-storage-sa@PROJECT_ID.iam.gserviceaccount.com" \
--role="roles/storage.objectViewer"

📘 What is GraphQL Variable?

GraphQL Variables are used to pass dynamic values into:

✔ Queries
✔ Mutations
✔ Filters

instead of hardcoding values.

Problem Without Variables

Example:

query{
 studentById(id:1){
   name
 }
}

Here:

id = hardcoded

To change ID, query must be modified again.

Solution → GraphQL Variables
query getStudent($id:ID){

 studentById(id:$id){
    name
 }
}

Now ID becomes dynamic.

Benefits of Variables
Benefit	Explanation
Dynamic Queries	Reusable queries
Cleaner Queries	Better readability
Security	Prevent query injection
Better Performance	Query caching
Reusability	Same query multiple inputs
GraphQL Variable Syntax
Query Structure
query queryName($variable:Type){

 field(argument:$variable){
   responseFields
 }
}
Variables JSON
{
 "variable":value
}

package com.example.demo.config;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import org.springframework.graphql.client.HttpGraphQlClient;

import org.springframework.web.reactive.function.client.WebClient;

@Configuration
public class GraphQLClientConfig {

    @Bean
    public HttpGraphQlClient client(){

        WebClient webClient =
                WebClient.builder()
                .baseUrl("http://localhost:8080/graphql")
                .build();

        return HttpGraphQlClient
                .builder(webClient)
                .build();
    }
}

Step 1: Create DTO
package com.example.demo.dto;

    private Long id;

Step 2: Create Service
package com.example.demo.service;

import com.example.demo.dto.Student;

import org.springframework.beans.factory.annotation.Autowired;

import org.springframework.graphql.client.HttpGraphQlClient;

import org.springframework.stereotype.Service;

import java.util.List;

@Service
public class StudentClientService {

    @Autowired
    private HttpGraphQlClient client;

    public List<Student> getStudents(){

        String query = """
            query{
               students{
                  id
                  name
                  age
               }
            }
            """;

        return client.document(query)
                .retrieve("students")
                .toEntityList(Student.class)
                .block();
    }
}

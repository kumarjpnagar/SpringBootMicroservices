

🚀 Chapter 1 — Apache Kafka Fundamentals (Ultra Deep Dive)

🧠 1. Why Kafka Exists (The Real Problem)

Before Kafka, systems looked like this:

Service A → Service B
Service A → Service C
Service B → Service D
Service C → Service D

👉 This creates N × M integrations (tight coupling)

❌ Problems:
Hard to scale
Hard to debug
Failures cascade
Adding new service = nightmare
✅ Kafka Solution: Central Nervous System

Kafka introduces:

Producers → KAFKA → Consumers

👉 Now it's N + M architecture

Producers don’t care who consumes
Consumers don’t care who produces
Systems are loosely coupled

Independent

🔑 7. Key-Based Routing (CRITICAL 🔥)

Now the most important concept.

❓ Without Key
producer.send(new ProducerRecord<>("orders", "data"));

👉 Kafka does:

Round-robin
Random distribution
Partition 0 → msg1
Partition 1 → msg2
Partition 2 → msg3
🔑 With Key
producer.send(new ProducerRecord<>("orders", "user123", "order-data"));

👉 Kafka uses:

partition = hash(key) % numPartitions
🎯 Result
"user123" → Partition 1
"user123" → Partition 1
"user123" → Partition 1
🔥 WHY THIS MATTERS

👉 Guarantees ordering per user

Example:

Order Created
Payment Done
Order Shipped

✔ Correct order maintained

⚠️ Without Key Problem
Partition 0 → Created
Partition 2 → Shipped
Partition 1 → Payment

❌ Order breaks

🧠 8. Partition Strategy Design (REAL WORLD)
🎯 Case 1: User-based system

👉 Use:

key = userId

✔ Ensures per-user ordering

🎯 Case 2: Order system

👉 Use:

key = orderId
🎯 Case 3: Logging

👉 Use:

No key (random)

✔ Better distribution

⚖️ 9. Scaling Strategy (VERY IMPORTANT 🔥)
🧠 Rule:

👉 Partitions = Parallelism

Example:
Topic partitions = 3
Consumers = 3
C1 → P0
C2 → P1
C3 → P2

✔ Perfect parallelism

❌ Wrong Design
Partitions = 2
Consumers = 5
C1 → P0
C2 → P1
C3 → idle
C4 → idle
C5 → idle

❌ Waste of resources

📌 Golden Rule

👉 #Consumers ≤ #Partitions

🚨 10. Increasing Partitions (Danger ⚠️)
❗ You CAN increase partitions
kafka-topics.sh --alter --partitions 5
❌ But Problem:

Key mapping changes!

Old: hash(key) % 3
New: hash(key) % 5

👉 Same key → different partition

🔥 Result:

❌ Ordering breaks

🚀 Chapter 4 — Consumers & Consumer Groups (Ultra Deep Dive)
🧠 1. What is a Kafka Consumer?

A consumer:

Reads messages from Kafka
Controls its own position (offset)
Pulls data (Kafka never pushes)

👉 Think:

Consumer = Smart reader with full control over progress

🔄 2. Poll-Based Model (CRITICAL 🔥)

Kafka uses pull model:

consumer.poll(Duration.ofMillis(100));
📊 Flow
Consumer → poll() → Broker → Fetch Data → Process
🔥 Why Poll?

✔ Consumer controls speed
✔ Handles backpressure
✔ Avoids overload

🧱 3. Consumer Groups (MOST IMPORTANT 🔥)
🧠 Concept

A consumer group = multiple consumers working together

Group: order-processors
📊 Example
Topic: orders (3 partitions)

Consumer Group:
C1, C2, C3
C1 → Partition 0
C2 → Partition 1
C3 → Partition 2
🔥 Rule

👉 One partition = one consumer (within group)

❗ Important

✔ Same group → share work
✔ Different groups → independent reading

⚡ 4. Parallelism (Scaling)
Perfect Scaling
Partitions = 3
Consumers = 3

✔ Max parallelism

Under-utilization
Partitions = 5
Consumers = 2

✔ Each handles multiple partitions

Over-provisioning ❌
Partitions = 2
Consumers = 5

❌ 3 consumers idle

🧠 Golden Rule

👉 Max parallelism = number of partitions

🔁 5. Rebalancing (VERY IMPORTANT 🔥)
❓ What is Rebalancing?

When consumers change, Kafka reassigns partitions.

🔄 Triggered When:
New consumer joins
Consumer crashes
Topic partitions change
📊 Example
Before:
C1 → P0, P1
C2 → P2
After (C3 joins):
C1 → P0
C2 → P1
C3 → P2
⚠️ Problem

During rebalance:

Consumers STOP processing ❌
Temporary downtime
🔥 Solution: Cooperative Rebalancing
props.put("partition.assignment.strategy",
"org.apache.kafka.clients.consumer.CooperativeStickyAssignor");

✔ Minimizes disruption
✔ Incremental reassignment

🧠 6. Offset Management (CRITICAL 🔥)
❓ What is Offset?

👉 Position of last processed message

Example
Partition 0:
[0] A
[1] B
[2] C

If consumer processed till B:

Committed offset = 2
⚠️ Key Point

👉 Offset stored in Kafka topic:

__consumer_offsets
🔁 7. Offset Commit Strategies
🔹 Auto Commit
props.put("enable.auto.commit", "true");
Kafka commits automatically
Risk: data loss ❌
🔹 Manual Commit (Recommended)
consumer.commitSync();

✔ Full control
✔ Safer

🔥 commitSync vs commitAsync
✅ commitSync()
consumer.commitSync();
Blocking
Guaranteed commit
Slower
⚡ commitAsync()
consumer.commitAsync();
Non-blocking
Faster
Risk of loss
⚖️ 8. Delivery Semantics
❌ At-most-once

Commit BEFORE processing

Commit → Process

Risk: message lost

✅ At-least-once (Most common)

Process → Commit

Process → Commit

Risk: duplicates possible

🟢 Exactly-once (Advanced)
Combine:
Idempotent producer
Transactions
📊 9. Consumer Lag (VERY IMPORTANT 🔥)
❓ What is Lag?
Lag = Latest Offset - Consumer Offset
Example
Latest = 100
Consumer = 80
Lag = 20
🚨 High Lag Means:
Consumer slow
System overloaded
Possible failure
📌 Monitoring Tools
CLI
JMX
Prometheus + Grafana
🧪 10. Full Java Consumer Example
Properties props = new Properties();

props.put("bootstrap.servers", "localhost:9092");
props.put("group.id", "order-group");
props.put("key.deserializer", "org.apache.kafka.common.serialization.StringDeserializer");
props.put("value.deserializer", "org.apache.kafka.common.serialization.StringDeserializer");

// Manual commit
props.put("enable.auto.commit", "false");

KafkaConsumer<String, String> consumer = new KafkaConsumer<>(props);

consumer.subscribe(Arrays.asList("orders"));

try {
    while (true) {
        ConsumerRecords<String, String> records =
            consumer.poll(Duration.ofMillis(100));

        for (ConsumerRecord<String, String> record : records) {
            System.out.println(
                "Partition: " + record.partition() +
                " Offset: " + record.offset() +
                " Value: " + record.value()
            );
        }

        consumer.commitSync(); // commit after processing
    }
} catch (WakeupException e) {
    // shutdown
} finally {
    consumer.close();
}
⚠️ 11. Graceful Shutdown (IMPORTANT 🔥)
Runtime.getRuntime().addShutdownHook(new Thread(() -> {
    consumer.wakeup();
}));

✔ Prevents:

Data loss
Stuck consumers

🚀 Chapter 5 — Brokers & Cluster Architecture (Ultra Deep Dive)

🧠 1. What is a Kafka Broker?

A broker is:

A Kafka server
Stores partitions (data)
Handles read/write requests

👉 Think:

Broker = Data node in distributed system

📊 Cluster Example
Broker 1
Broker 2
Broker 3

👉 Together they form:

Kafka Cluster
🧱 2. Partition Distribution Across Brokers
Example Topic: orders (3 partitions, replication = 2)
Partition 0 → Broker 1
Partition 1 → Broker 2
Partition 2 → Broker 3

With replication:

P0 → B1 (Leader), B2 (Follower)
P1 → B2 (Leader), B3 (Follower)
P2 → B3 (Leader), B1 (Follower)
🔥 3. Leader & Follower (CRITICAL 🔥)
🧠 Concept

Each partition has:

1 Leader
N Followers
📊 Flow
Producer → Leader → Followers
Consumer → Leader
✅ Key Rules

✔ All writes go to Leader
✔ All reads go from Leader (default)
✔ Followers only replicate

⚠️ Why?

👉 Ensures:

Consistency
Simplicity
🔁 4. Replication (Fault Tolerance)
❓ Why Replication?

👉 To prevent data loss

📊 Example
Replication Factor = 3

Partition 0:
B1 (Leader)
B2 (Follower)
B3 (Follower)
🔄 Flow
Producer → Leader
Leader → Followers (replicate)
ACK → Producer
🧠 5. ISR (In-Sync Replicas) 🔥
❓ What is ISR?

👉 Set of replicas that are fully caught up

Example:
ISR = [B1, B2, B3]

If B3 lags:

ISR = [B1, B2]
⚠️ Why Important?

ACK depends on ISR:

acks=all

👉 Means:

Wait for all ISR replicas
⚖️ 6. min.insync.replicas (VERY IMPORTANT 🔥)
Config:
min.insync.replicas=2
Scenario:
Replication factor = 3
ISR = 2 brokers alive

✔ Write allowed

If ISR < min.insync.replicas:

❌ Write fails

🔥 WHY?

👉 Prevents:

Data loss
Weak durability
🧠 7. High Watermark (Consistency 🔥)
❓ What is it?

👉 The last committed offset replicated to all ISR

Example:
Leader log:      [0,1,2,3,4]
Follower log:    [0,1,2,3]
High watermark = 3
Rule:

👉 Consumers can only read till high watermark

✔ Ensures consistency
✔ Avoids dirty reads

🔄 8. Leader Election (Failure Handling)
Scenario:

Leader crashes ❌

Old Leader: B1
New Leader selected:
New Leader: B2
How?
From ISR only ✅
Not from out-of-sync replicas ❌
🔥 Result:

✔ No data loss
✔ Fast recovery

🧠 9. Controller (Cluster Brain)
❓ What is Controller?

👉 One broker acts as Controller

Responsibilities:
Leader election
Detect broker failure
Manage cluster metadata
📊 Example:
Controller → Broker 2
⚠️ If Controller fails?

👉 New controller elected automatically

🧬 10. Zookeeper vs KRaft (Modern Kafka 🔥)

👉 Kafka without Zookeeper

🚀 Chapter 7 — Offset Management & Delivery Semantics (Ultra Deep Dive)

🧠 1. Why Offsets Matter So Much

Kafka does NOT track what you processed ❌
👉 YOU control correctness via offsets

📊 Core Idea
Offset = position of last processed message
Example
Partition 0:
[0] A
[1] B
[2] C
[3] D

If consumer processed till C:

Committed Offset = 3

👉 Next read starts from D

🧱 2. Where Offsets Are Stored

Kafka stores offsets in:

__consumer_offsets

👉 Internal Kafka topic

🧠 Key Insight

Offsets are stored:

Per consumer group
Per partition
Example
Group: order-group

Partition 0 → offset 10
Partition 1 → offset 5
⚖️ 3. Delivery Semantics (CORE 🔥)

This defines data correctness guarantee

❌ 3.1 At-Most-Once (Risky)
Flow
Commit → Process
Example
consumer.commitSync();  // commit first
process(record);        // process later
❗ Problem

If crash happens:

Commit done ❌
Processing NOT done ❌

👉 Message LOST

📌 Use Case
Logs
Metrics (loss acceptable)
✅ 3.2 At-Least-Once (Most Used 🔥)
Flow
Process → Commit
Example
process(record);
consumer.commitSync();
❗ Problem

If crash happens:

Processing done ✔
Commit NOT done ❌

👉 Message processed AGAIN

✔ Result
No data loss
Possible duplicates
📌 Use Case
Payments (with idempotent handling)
Orders
🟢 3.3 Exactly-Once (Advanced 🔥🔥)
Goal

✔ No duplicates
✔ No data loss

Requires:
Idempotent Producer
Transactions
Producer Config
props.put("enable.idempotence", "true");
props.put("transactional.id", "txn-1");
Transaction Flow
producer.initTransactions();

producer.beginTransaction();

producer.send(record);

// also send offsets to transaction
producer.sendOffsetsToTransaction(offsets, groupId);

producer.commitTransaction();
🧠 Result

✔ Atomic:

Message write
Offset commit

 * STEP 1: Connect to Wikimedia live stream

public class WikimediaChangesProducer {

    public static void main(String[] args) throws InterruptedException {

        // ===============================
        // STEP 1: CREATE PRODUCER CONFIG
        // ===============================
        Properties props = new Properties();

        props.put(ProducerConfig.BOOTSTRAP_SERVERS_CONFIG, "127.0.0.1:9092");

        props.put(ProducerConfig.ENABLE_IDEMPOTENCE_CONFIG, "true");

        // ===============================

        KafkaProducer<String, String> producer = new KafkaProducer<>(props);

        // ===============================
        String url = "https://stream.wikimedia.org/v2/stream/recentchange";

        EventHandler handler = new WikimediaChangeHandler(producer, topic);

        EventSource eventSource = new EventSource.Builder(handler, URI.create(url)).build();

        // ===============================

        eventSource.start();

✅ WikimediaChangeHandler.java
package producer;

import com.launchdarkly.eventsource.EventHandler;
import com.launchdarkly.eventsource.MessageEvent;
import org.apache.kafka.clients.producer.*;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

/**
 * Handles each incoming Wikimedia event
 * Sends it to Kafka
 */
public class WikimediaChangeHandler implements EventHandler {

    private final KafkaProducer<String, String> producer;
    private final String topic;
    private final Logger log = LoggerFactory.getLogger(WikimediaChangeHandler.class);

    public WikimediaChangeHandler(KafkaProducer<String, String> producer, String topic) {
        this.producer = producer;
        this.topic = topic;
    }

    @Override
    public void onOpen() {
        log.info("Stream opened!");
    }

    @Override
    public void onClosed() {
        log.info("Stream closed!");
        producer.close();
    }

    /**
     * MAIN LOGIC:
     * Every event comes here
     */
    @Override
    public void onMessage(String event, MessageEvent messageEvent) {

        String data = messageEvent.getData();

        log.info("Received Event: {}", data);

        // Send to Kafka (ASYNC)
        producer.send(new ProducerRecord<>(topic, data),
                (metadata, exception) -> {
                    if (exception == null) {
                        log.info("Sent to partition {} offset {}",
                                metadata.partition(),
                                metadata.offset());
                    } else {
                        log.error("Error sending message", exception);
                    }
                });
    }

    @Override
    public void onComment(String comment) {}

    @Override
    public void onError(Throwable t) {
        log.error("Stream error", t);
    }
}

package consumer;

import com.google.gson.JsonParser;
import org.apache.http.HttpHost;
import org.apache.kafka.clients.consumer.*;
import org.apache.kafka.common.serialization.StringDeserializer;
import org.opensearch.action.bulk.*;
import org.opensearch.action.index.IndexRequest;
import org.opensearch.client.*;
import org.opensearch.client.indices.*;
import org.opensearch.common.xcontent.XContentType;

import java.time.Duration;
import java.util.Collections;
import java.util.Properties;

/**
 * Reads Kafka → Writes to OpenSearch
 */
public class OpenSearchConsumer {

    // ===============================
    // CREATE OPENSEARCH CLIENT
    // ===============================
    public static RestHighLevelClient createClient() {
        return new RestHighLevelClient(
                RestClient.builder(new HttpHost("localhost", 9200, "http"))
        );
    }

    // ===============================
    // CREATE KAFKA CONSUMER
    // ===============================
    public static KafkaConsumer<String, String> createConsumer() {

        Properties props = new Properties();

        props.put("bootstrap.servers", "127.0.0.1:9092");
        props.put("group.id", "opensearch-consumer");

        props.put("key.deserializer", StringDeserializer.class.getName());
        props.put("value.deserializer", StringDeserializer.class.getName());

        props.put("auto.offset.reset", "latest");

        // Disable auto commit (IMPORTANT)
        props.put("enable.auto.commit", "false");

        return new KafkaConsumer<>(props);
    }

    // ===============================
    // EXTRACT UNIQUE ID (IDEMPOTENCY)
    // ===============================
    private static String extractId(String json) {
        return JsonParser.parseString(json)
                .getAsJsonObject()
                .get("meta")
                .getAsJsonObject()
                .get("id")
                .getAsString();
    }

    public static void main(String[] args) throws Exception {

        RestHighLevelClient client = createClient();
        KafkaConsumer<String, String> consumer = createConsumer();

        consumer.subscribe(Collections.singleton("wikimedia.recentchange"));

        // ===============================
        // CREATE INDEX IF NOT EXISTS
        // ===============================
        boolean exists = client.indices()
                .exists(new GetIndexRequest("wikimedia"), RequestOptions.DEFAULT);

        if (!exists) {
            client.indices().create(
                    new CreateIndexRequest("wikimedia"),
                    RequestOptions.DEFAULT
            );
        }

        // ===============================
        // MAIN LOOP
        // ===============================
        while (true) {

            ConsumerRecords<String, String> records =
                    consumer.poll(Duration.ofMillis(3000));

            BulkRequest bulkRequest = new BulkRequest();

            for (ConsumerRecord<String, String> record : records) {

                try {
                    String id = extractId(record.value());

                    IndexRequest request = new IndexRequest("wikimedia")
                            .source(record.value(), XContentType.JSON)
                            .id(id); // prevents duplicates

                    bulkRequest.add(request);

                } catch (Exception e) {
                    System.out.println("Bad JSON skipped");
                }
            }

            // ===============================
            // BULK INSERT
            // ===============================
            if (bulkRequest.numberOfActions() > 0) {

                BulkResponse response =
                        client.bulk(bulkRequest, RequestOptions.DEFAULT);

                System.out.println("Inserted: " + response.getItems().length);

                // Commit ONLY after success
                consumer.commitSync();
            }
        }
    }
}

package streams;

import org.apache.kafka.streams.kstream.KStream;

public class BotCountStreamBuilder {

    private final KStream<String, String> stream;

    public BotCountStreamBuilder(KStream<String, String> stream) {
        this.stream = stream;
    }

    public void setup() {

        stream
            .mapValues(value -> value.contains("\"bot\":true") ? "bot" : "non-bot")
            .groupBy((key, value) -> value)
            .count()
            .toStream()
            .to("wikimedia.stats.bots");
    }
}

package streams;

public class EventCountTimeseriesBuilder {

                .whenComplete((result, ex) -> {
                    if (ex == null) {

                    } else {
                        System.out.println("Error: " + ex.getMessage());
                    }
                });
    }
}

/**

 * Commit BEFORE processing
 */
public class AtMostOnceConsumer {

    public static void main(String[] args) {

        Properties props = new Properties();

        props.put("bootstrap.servers", "localhost:9092");
        props.put("group.id", "at-most-once-group");

        props.put("key.deserializer",
                StringDeserializer.class.getName());

        props.put("value.deserializer",
                StringDeserializer.class.getName());

        props.put("enable.auto.commit", "false");

        KafkaConsumer<String, String> consumer =
                new KafkaConsumer<>(props);

        consumer.subscribe(Collections.singleton("orders"));

        while (true) {

            ConsumerRecords<String, String> records =
                    consumer.poll(Duration.ofMillis(1000));

            // ❌ COMMIT FIRST
            consumer.commitSync();

            for (ConsumerRecord<String, String> record : records) {

                System.out.println("Processing: " + record.value());

                // Simulate crash
                if (record.value().contains("FAIL")) {
                    System.exit(1);
                }
            }
        }
    }
}

package semantics;

import org.apache.kafka.clients.producer.*;
import org.apache.kafka.common.serialization.StringSerializer;

import java.util.Properties;

/**
 * EXACTLY ONCE PRODUCER
 */
public class TransactionalProducer {

    public static void main(String[] args) {

        Properties props = new Properties();

        props.put("bootstrap.servers", "localhost:9092");

        props.put("key.serializer",
                StringSerializer.class.getName());

        props.put("value.serializer",
                StringSerializer.class.getName());

        // IMPORTANT
        props.put("enable.idempotence", "true");

        props.put("acks", "all");

        props.put("transactional.id", "txn-1");

        KafkaProducer<String, String> producer =
                new KafkaProducer<>(props);

        // Initialize transaction
        producer.initTransactions();

        try {

            producer.beginTransaction();

            producer.send(new ProducerRecord<>(
                    "orders",
                    "order-1"
            ));

            producer.send(new ProducerRecord<>(
                    "orders",
                    "order-2"
            ));

            // Commit ALL atomically
            producer.commitTransaction();

            System.out.println("Transaction committed");

        } catch (Exception e) {

            producer.abortTransaction();

            System.out.println("Transaction aborted");
        }

        producer.close();
    }
}

package retry;

import lombok.extern.slf4j.Slf4j;
import org.springframework.kafka.annotation.KafkaListener;
import org.springframework.kafka.listener.DefaultErrorHandler;
import org.springframework.stereotype.Service;
import org.springframework.util.backoff.FixedBackOff;

@Slf4j
@Service
public class FixedBackoffConsumer {

    @KafkaListener(topics = "orders")
    public void consume(String message) {

        log.info("Processing: {}", message);

        if (message.contains("FAIL")) {
            throw new RuntimeException("Temporary failure");
        }

        log.info("SUCCESS");
    }

    /**
     * Retry 3 times
     * Wait 5 seconds each
     */
    public DefaultErrorHandler errorHandler() {

        FixedBackOff backOff =
                new FixedBackOff(5000L, 3);

        return new DefaultErrorHandler(backOff);
    }
}

    ExponentialBackOff backOff =
            new ExponentialBackOff();

    backOff.setInitialInterval(1000L);

    backOff.setMultiplier(2.0);

    backOff.setMaxInterval(30000L);

    DefaultErrorHandler handler =
            new DefaultErrorHandler(
                    new DeadLetterPublishingRecoverer(template),
                    backOff
            );

    return handler;
}

🔥 1️⃣ CONSUMER REBALANCING SIMULATION
🧠 What is Rebalancing?

Kafka redistributes partitions when:

Consumer leaves
Consumer crashes
📊 Example

Partitions: 4

Consumers:

Consumer-2
📊 Assignment

Kafka rebalances:

Consumer-1 → P0, P1, P2, P3
🧪 HANDS-ON
✅ Consumer Code
package rebalance;

import org.apache.kafka.clients.consumer.*;
import org.apache.kafka.common.serialization.StringDeserializer;

import java.time.Duration;
import java.util.Collections;
import java.util.Properties;

public class RebalanceConsumer {

    public static void main(String[] args) {

        String consumerName = args[0];

        Properties props = new Properties();

        props.put("bootstrap.servers", "localhost:9092");

        props.put("group.id", "rebalance-group");

        props.put("key.deserializer",
                StringDeserializer.class.getName());

        props.put("value.deserializer",
                StringDeserializer.class.getName());

        KafkaConsumer<String, String> consumer =
                new KafkaConsumer<>(props);

        consumer.subscribe(
                Collections.singleton("orders"),
                new ConsumerRebalanceListener() {

                    @Override
                    public void onPartitionsRevoked(
                            Collection<TopicPartition> partitions) {

                        System.out.println(
                                consumerName +
                                " LOST partitions " + partitions
                        );
                    }

                    @Override
                    public void onPartitionsAssigned(
                            Collection<TopicPartition> partitions) {

                        System.out.println(
                                consumerName +
                                " GOT partitions " + partitions
                        );
                    }
                }
        );

        while (true) {

            ConsumerRecords<String, String> records =
                    consumer.poll(Duration.ofMillis(1000));

            for (ConsumerRecord<String, String> record : records) {

                System.out.println(
                        consumerName +
                        " processed " +
                        record.value()
                );
            }
        }
    }
}

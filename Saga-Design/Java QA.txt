import java.util.Map;
import java.util.function.Function;
import java.util.stream.Collectors;

public class CharacterCount {
    public static void main(String[] args) {
        String s = "abcdefabc"; // Example string, 'a' and 'c' appear twice

        // Use streams to count characters
        Map<Character, Long> charCounts = s.chars()
            .mapToObj(c -> (char) c) // Convert IntStream to Stream<Character>
            .collect(Collectors.groupingBy(
                Function.identity(), // Group by the character itself
                Collectors.counting() // Count occurrences of each character
            ));

        // Print the results
        System.out.println("Character counts for string \"" + s + "\":");
        charCounts.forEach((character, count) -> 
            System.out.println(character + "=" + count)
        );
    }
}
		
---

Explanation of the code:
s.chars(): This method converts the string s into an IntStream where each element is the ASCII value of a character.
.mapToObj(c -> (char) c): This maps each integer (ASCII value) in the IntStream to its corresponding Character object to work with the groupingBy collector.
.collect(Collectors.groupingBy(...)): This is a terminal operation that collects the stream elements into a Map.
Function.identity(): This is the classifier function that groups elements by their own value (i.e., all 'a's are grouped together, all 'b's together, etc.).
Collectors.counting(): This is a downstream collector used to count the number of elements in each group, resulting in a Map<Character, Long>

import java.util.*;
import java.util.stream.Collectors;

public class SortHashMapByValue {
    public static void main(String[] args) {
        Map<Integer, String> map = new HashMap<>();
        map.put(1, "x");
        map.put(2, "s");
        map.put(3, "z");

        // Sort by value (ascending)
        Map<Integer, String> sortedMap = map.entrySet().stream()
                .sorted(Map.Entry.comparingByValue())
                .collect(Collectors.toMap(
                        Map.Entry::getKey,
                        Map.Entry::getValue,
                        (v1, v2) -> v1,
                        LinkedHashMap::new
                ));

        System.out.println("Sorted Map: " + sortedMap);
    }
}

Key Steps:
.stream() & .sorted(): Converts the map to a stream and uses Map.Entry.comparingByValue() to sort by values.
.collect(): Uses Collectors.toMap to collect results, specifically using LinkedHashMap::new to maintain the sorted order.

public class EmployeeProcessor {
    public static void main(String[] args) {
        // Example with data
        Optional<List<Employee>> employeesOpt = getEmployees();

                list.stream()
                    .filter(e -> e.getAge() > 30)
                    .forEach(e -> e.setSalary(e.getSalary() + 1000));

            }
        });

import java.util.*;
import java.util.function.Function;
import java.util.stream.Collectors;

public class RepeatedStringsCount {
    public static void main(String[] args) {

        List<String> list = Arrays.asList("aa","cc","bb","aa","dd","bb");

        Map<String, Long> result =
                list.stream()
                    .collect(Collectors.groupingBy(
                            Function.identity(),
                            Collectors.counting()))
                    .entrySet()
                    .stream()
                    .filter(e -> e.getValue() > 1)
                    .collect(Collectors.toMap(
                            Map.Entry::getKey,
                            Map.Entry::getValue));

        result.forEach((k,v) -> System.out.println(k + " -> " + v));
    }
}

import java.util.Map;
import java.util.function.Function;
import java.util.stream.Collectors;

public class FirstNonRepeatedChar {

    public static Character findFirstNonRepeatedChar(String s) {
        // Line 1: Convert the string to a stream of characters and count occurrences.
        Map<Character, Long> counts = s.chars()
            // Line 2: Convert each int (ASCII value) from the stream back to a Character object.
            .mapToObj(c -> (char) c)
            // Line 3: Collect characters into a LinkedHashMap (maintains order)
            // with counting collector to store frequency.
            .collect(Collectors.groupingBy(Function.identity(), LinkedHashMap::new, Collectors.counting()));
        
        // Line 4: Find the first entry in the map with a count of 1.
        return counts.entrySet().stream()
            // Line 5: Filter map entries to find those where the count is equal to 1.
            .filter(entry -> entry.getValue() == 1L)
            // Line 6: Get the first element of the filtered stream (due to LinkedHashMap order).
            .map(Map.Entry::getKey)
            // Line 7: Get the character if present, otherwise return null.
            .findFirst()
            .orElse(null);
    }

    public static void main(String[] args) {
        String s1 = "swiss";

            System.out.println("The first non-repeated character in \"" + s1 + "\" is: " + firstNonRepeated);
        } else {
            System.out.println("No non-repeated character found in \"" + s1 + "\".");
        }
    }

Line 2: .mapToObj(c -> (char) c): This maps each integer from the IntStream back to its char representation, resulting in a Stream<Character>.

Line 3: .collect(Collectors.groupingBy(Function.identity(), LinkedHashMap::new, Collectors.counting())): This is a crucial step that collects the stream elements into a Map.
Function.identity(): The characters themselves are used as the keys in the map.
LinkedHashMap::new: A LinkedHashMap is specified to ensure the order of insertion is preserved. This is essential to find the first non-repeated character.
Collectors.counting(): This counts the occurrences of each character, which become the values in the map.

Line 4: .entrySet().stream(): This creates a stream from the map's entry set (Map.Entry<Character, Long>), allowing further stream operations on the character-count pairs.

Line 5: .filter(entry -> entry.getValue() == 1L): This filters the stream to keep only the entries where the count (value) is exactly 1, meaning the character is non-repeated.

Line 6: .map(Map.Entry::getKey): This maps the filtered entries back to their character keys.

Line 7: .findFirst(): This is a short-circuiting terminal operation that returns an Optional<Character> containing the first character that satisfies the criteria, or an empty Optional if no such character exists.

public class SecondNonRepeatedChar {

        String input = "swiss";

        Character result = input.chars()                 // Convert String ? IntStream
                .mapToObj(c -> (char) c)                 // Convert int ? Character
                .collect(Collectors.groupingBy(
                        Function.identity(),             // Group characters
                        LinkedHashMap::new,              // Maintain insertion order

                .orElse(null);

import java.util.Arrays;

public class CountUsingReduce {
    public static void main(String[] args) {
        int[] arr = {1, 3, 4, 6, 7, 2};

        int count = Arrays.stream(arr)
                          .boxed() // convert IntStream -> Stream<Integer>
                          .reduce(0, (c, e) -> c + 1);

        System.out.println("Count: " + count);

}

        String s = "abcdefabc"; // Example string, 'a' and 'c' appear twice

        // Use streams to count characters
        Map<Character, Long> charCounts = s.chars()
            .mapToObj(c -> (char) c) // Convert IntStream to Stream<Character>
            .collect(Collectors.groupingBy(
                Function.identity(), // Group by the character itself
                Collectors.counting() // Count occurrences of each character
            ));

        // Print the results
        System.out.println("Character counts for string \"" + s + "\":");
        charCounts.forEach((character, count) -> 
            System.out.println(character + "=" + count)
        );
    }
}

Explanation of the code:
s.chars(): This method converts the string s into an IntStream where each element is the ASCII value of a character.
.mapToObj(c -> (char) c): This maps each integer (ASCII value) in the IntStream to its corresponding Character object to work with the groupingBy collector.
.collect(Collectors.groupingBy(...)): This is a terminal operation that collects the stream elements into a Map.
Function.identity(): This is the classifier function that groups elements by their own value (i.e., all 'a's are grouped together, all 'b's together, etc.).
Collectors.counting(): This is a downstream collector used to count the number of elements in each group, resulting in a Map<Character, Long>

public class SortHashMapByValue {
    public static void main(String[] args) {
        Map<Integer, String> map = new HashMap<>();
        map.put(1, "x");
        map.put(2, "s");
        map.put(3, "z");

        // Sort by value (ascending)
        Map<Integer, String> sortedMap = map.entrySet().stream()
                .sorted(Map.Entry.comparingByValue())
                .collect(Collectors.toMap(
                        Map.Entry::getKey,
                        Map.Entry::getValue,
                        (v1, v2) -> v1,
                        LinkedHashMap::new
                ));

        System.out.println("Sorted Map: " + sortedMap);
    }
}

Key Steps:
.stream() & .sorted(): Converts the map to a stream and uses Map.Entry.comparingByValue() to sort by values.
.collect(): Uses Collectors.toMap to collect results, specifically using LinkedHashMap::new to maintain the sorted order.

	What is  CompletableFuture?
	<============>
CompletableFuture is a class in java.util.concurrent package that implements the Future and CompletionStage Interface. It represents a future result of an asynchronous computation. It can be thought of as a container that holds the result of an asynchronous operation that is being executed in a different thread. It provides a number of methods to perform various operations on the result of the async computation.

Creating a CompletableFuture:
	<================>
To create an instance of CompletableFuture, we can use the static method supplyAsync provided by CompletableFuture class which takes Supplier as an argument. Supplier is a Functional Interface that takes no value and returns a result.

import java.util.concurrent.*;
  
class GFG {
    public static void main(String[] args) throws Exception
    {
        CompletableFuture<String> greetingFuture
            = CompletableFuture.supplyAsync(() -> {
                  // some async computation
                  return "Hello from CompletableFuture";
              });
  
        System.out.println(greetingFuture.get());
    }
}

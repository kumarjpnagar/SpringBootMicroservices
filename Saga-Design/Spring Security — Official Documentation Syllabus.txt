1.1 Authentication vs Authorization

These are the two pillars of every security system. Often confused, but fundamentally different.

Authentication = Who are you? (Identity verification)
Authorization = What can you do? (Permission enforcement)

In Spring Security, this maps directly to two separate filter chains.

Key distinction in HTTP status codes:

401 Unauthorized → Authentication failed (identity unknown)
403 Forbidden → Authorization failed (identity known, but permission denied)
java
// Spring Security maps these automatically in ExceptionTranslationFilter
// AuthenticationException  → 401
// AccessDeniedException    → 403
1.2 Common Security Threats
SQL Injection

The most dangerous vulnerability (OWASP #1 for years). An attacker injects malicious SQL into input fields.

java
// VULNERABLE — never do this
String query = "SELECT * FROM users WHERE username='" + username + "'";
// Input: admin' OR '1'='1  → bypasses auth entirely

// SAFE — always use PreparedStatement or JPA/Hibernate
@Repository
public interface UserRepository extends JpaRepository<User, Long> {
    // Spring Data auto-generates safe parameterized queries
    Optional<User> findByUsername(String username);

    // Custom query — use @Param, never string concat
    @Query("SELECT u FROM User u WHERE u.email = :email AND u.active = true")
    Optional<User> findActiveByEmail(@Param("email") String email);
}

// JDBC Template — also safe
jdbcTemplate.queryForObject(
    "SELECT * FROM users WHERE id = ?",
    new Object[]{userId},
    userRowMapper
);
Cross-Site Scripting (XSS)

Attacker injects malicious scripts into pages viewed by other users.

java
// VULNERABLE — rendering raw user input in HTML
model.addAttribute("comment", userInput); // if userInput = <script>steal()</script>

// SAFE approach 1: Thymeleaf auto-escapes by default
// th:text escapes HTML, th:utext does NOT (avoid th:utext with user input)

// SAFE approach 2: Spring Security HTTP headers (enabled by default)
@Bean
public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
    http
        .headers(headers -> headers
            // Prevents browser from MIME-sniffing
            .contentTypeOptions(Customizer.withDefaults())
            // Enables XSS filter in older browsers
            .xssProtection(Customizer.withDefaults())
            // Content Security Policy — restricts script sources
            .contentSecurityPolicy(csp -> csp
                .policyDirectives("default-src 'self'; script-src 'self'; object-src 'none'")
            )
        );
    return http.build();
}

// SAFE approach 3: Sanitize HTML input with OWASP Java HTML Sanitizer
// <dependency> org.owasp.antisamy / antisamy </dependency>
PolicyFactory policy = Sanitizers.FORMATTING.and(Sanitizers.LINKS);
String safeOutput = policy.sanitize(userInput);
CSRF (Cross-Site Request Forgery)

Tricks authenticated users into submitting malicious requests.

java
// How CSRF works:
// 1. User is logged into bank.com (has valid session cookie)
// 2. User visits evil.com which has: <img src="bank.com/transfer?to=evil&amount=9999">
// 3. Browser auto-sends the cookie → bank executes the transfer

// Spring Security CSRF protection (enabled by default for stateful apps)
@Bean
public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
    http
        // For stateful web apps — keep CSRF enabled (default)
        .csrf(csrf -> csrf
            .csrfTokenRepository(CookieCsrfTokenRepository.withHttpOnlyFalse())
            // For SPA — store token in cookie, JS reads it
        );

    // For stateless REST APIs with JWT — disable CSRF (no session = no CSRF risk)
    // .csrf(csrf -> csrf.disable())

    return http.build();
}

// Security configuration — production-ready baseline
@Configuration
@EnableWebSecurity
@EnableMethodSecurity(prePostEnabled = true)          // enables @PreAuthorize
public class SecurityConfig {

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        return http
            // 1. Session management — stateless for REST APIs
            .sessionManagement(session -> session
                .sessionCreationPolicy(SessionCreationPolicy.STATELESS)
            )
            // 2. CSRF — disabled for stateless JWT-based APIs
            .csrf(csrf -> csrf.disable())
            // 3. Authorization rules
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/api/auth/**", "/actuator/health").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated()
            )
            // 4. JWT filter — added before UsernamePasswordAuthenticationFilter
            .addFilterBefore(jwtAuthFilter(), UsernamePasswordAuthenticationFilter.class)
            // 5. Exception handling
            .exceptionHandling(ex -> ex
                .authenticationEntryPoint(customAuthEntryPoint())
                .accessDeniedHandler(customAccessDeniedHandler())
            )
            // 6. Security headers
            .headers(headers -> headers
                .frameOptions(HeadersConfigurer.FrameOptionsConfig::deny)
                .contentSecurityPolicy(csp ->
                    csp.policyDirectives("default-src 'self'"))
            )
            .build();
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        // BCrypt with strength 12 — production standard
        return new BCryptPasswordEncoder(12);
    }

    @Bean
    public AuthenticationManager authenticationManager(
            AuthenticationConfiguration config) throws Exception {
        return config.getAuthenticationManager();
    }
}

// Custom AuthenticationEntryPoint — returns JSON instead of redirect
@Component
public class CustomAuthEntryPoint implements AuthenticationEntryPoint {

    @Override
    public void commence(HttpServletRequest request,
                         HttpServletResponse response,
                         AuthenticationException ex) throws IOException {
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);

        Map<String, Object> body = Map.of(
            "status", 401,
            "error", "Unauthorized",
            "message", ex.getMessage(),
            "path", request.getServletPath(),
            "timestamp", Instant.now().toString()
        );

        new ObjectMapper().writeValue(response.getOutputStream(), body);
    }
}
java
// Custom AccessDeniedHandler — JSON 403 response
@Component
public class CustomAccessDeniedHandler implements AccessDeniedHandler {

    @Override
    public void handle(HttpServletRequest request,
                       HttpServletResponse response,
                       AccessDeniedException ex) throws IOException {
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        response.setStatus(HttpServletResponse.SC_FORBIDDEN);

        Map<String, Object> body = Map.of(
            "status", 403,
            "error", "Forbidden",
            "message", "You don't have permission to access this resource",
            "path", request.getServletPath()
        );

        new ObjectMapper().writeValue(response.getOutputStream(), body);
    }
}

@Service
@RequiredArgsConstructor
public class CustomUserDetailsService implements UserDetailsService {

    private final UserRepository userRepository;

    @Override
    public UserDetails loadUserByUsername(String username)
            throws UsernameNotFoundException {
        return userRepository.findByUsername(username)
            .map(user -> org.springframework.security.core.userdetails.User
                .withUsername(user.getUsername())
                .password(user.getPassword())       // already BCrypt-hashed in DB
                .roles(user.getRoles().toArray(String[]::new))
                .build()
            )
            .orElseThrow(() ->
                new UsernameNotFoundException("User not found: " + username));
    }

3.1 SecurityFilterChain — Complete Configuration
java
// Full enterprise SecurityFilterChain setup
// Three separate chains for different parts of the app

@Configuration
@EnableWebSecurity
@EnableMethodSecurity(prePostEnabled = true, securedEnabled = true)
@RequiredArgsConstructor
public class SecurityConfig {

    private final JwtAuthenticationFilter jwtAuthFilter;
    private final CustomUserDetailsService userDetailsService;
    private final CustomAuthEntryPoint authEntryPoint;
    private final CustomAccessDeniedHandler accessDeniedHandler;

    // ─────────────────────────────────────────────
    // Chain 1: Actuator — @Order(1) = highest priority
    // ─────────────────────────────────────────────
    @Bean
    @Order(1)
    public SecurityFilterChain actuatorChain(HttpSecurity http) throws Exception {
        return http
            .securityMatcher("/actuator/**")
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/actuator/health",
                                 "/actuator/info").permitAll()
                .anyRequest().hasRole("MONITORING")
            )
            .httpBasic(Customizer.withDefaults())
            .sessionManagement(s -> s
                .sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .build();
    }

    // ─────────────────────────────────────────────
    // Chain 2: REST API — @Order(2) — JWT stateless
    // ─────────────────────────────────────────────
    @Bean
    @Order(2)
    public SecurityFilterChain apiChain(HttpSecurity http) throws Exception {
        return http
            .securityMatcher("/api/**")
            .csrf(csrf -> csrf.disable())
            .sessionManagement(s -> s
                .sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers(HttpMethod.POST, "/api/auth/login",
                                               "/api/auth/register",
                                               "/api/auth/refresh").permitAll()
                .requestMatchers(HttpMethod.GET,  "/api/public/**").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .requestMatchers("/api/reports/**").hasAnyRole("ADMIN", "MANAGER")
                .requestMatchers(HttpMethod.DELETE).hasRole("ADMIN")
                .anyRequest().authenticated()
            )
            .addFilterBefore(jwtAuthFilter,
                             UsernamePasswordAuthenticationFilter.class)
            .exceptionHandling(ex -> ex
                .authenticationEntryPoint(authEntryPoint)
                .accessDeniedHandler(accessDeniedHandler)
            )
            .build();
    }

    // ─────────────────────────────────────────────
    // Chain 3: Web MVC — @Order(3) — Form login + session
    // ─────────────────────────────────────────────
    @Bean
    @Order(3)
    public SecurityFilterChain webChain(HttpSecurity http) throws Exception {
        return http
            .securityMatcher("/**")           // catch-all — runs last
            .authorizeHttpRequests(auth -> auth
                .requestMatchers("/", "/public/**",
                                 "/css/**", "/js/**",
                                 "/images/**").permitAll()
                .requestMatchers("/admin/**").hasRole("ADMIN")
                .requestMatchers("/user/**").hasRole("USER")
                .anyRequest().authenticated()
            )
            .formLogin(form -> form
                .loginPage("/login")
                .loginProcessingUrl("/login")
                .defaultSuccessUrl("/dashboard", true)
                .failureUrl("/login?error=true")
                .permitAll()
            )
            .logout(logout -> logout
                .logoutUrl("/logout")
                .logoutSuccessUrl("/login?logout=true")
                .invalidateHttpSession(true)
                .deleteCookies("JSESSIONID", "remember-me")
                .clearAuthentication(true)
            )
            .rememberMe(rm -> rm
                .key("uniqueAndSecretKey")
                .tokenValiditySeconds(86400 * 14)   // 14 days
                .userDetailsService(userDetailsService)
            )
            .sessionManagement(s -> s
                .sessionCreationPolicy(SessionCreationPolicy.IF_REQUIRED)
                .maximumSessions(1)
                .maxSessionsPreventsLogin(false)    // new login kicks old session
            )
            .build();
    }

    @Bean
    public PasswordEncoder passwordEncoder() {
        return new BCryptPasswordEncoder(12);
    }

    @Bean
    public AuthenticationManager authManager(
            AuthenticationConfiguration config) throws Exception {
        return config.getAuthenticationManager();
    }
}
3.2 Role-Based Security — Every Pattern
java
// ── URL-level rules (inside SecurityFilterChain) ──────────────────────────

.authorizeHttpRequests(auth -> auth

    // 1. Permit all — no auth required
    .requestMatchers("/public/**").permitAll()

    // 2. Must be authenticated (any role)
    .requestMatchers("/profile/**").authenticated()

    // 3. Single role
    .requestMatchers("/admin/**").hasRole("ADMIN")
    // hasRole("ADMIN") is shorthand for hasAuthority("ROLE_ADMIN")

    // 4. Any of multiple roles
    .requestMatchers("/reports/**").hasAnyRole("ADMIN", "MANAGER")

    // 5. Fine-grained authority (not a role)
    .requestMatchers("/api/payments/**").hasAuthority("payment:write")

    // 6. SpEL expression — full power
    .requestMatchers("/api/sensitive/**")
        .access(new WebExpressionAuthorizationManager(
            "hasRole('ADMIN') and hasIpAddress('192.168.1.0/24')"
        ))

    // 7. HTTP method scoped
    .requestMatchers(HttpMethod.GET,    "/api/products/**").hasRole("USER")
    .requestMatchers(HttpMethod.POST,   "/api/products/**").hasRole("MANAGER")
    .requestMatchers(HttpMethod.PUT,    "/api/products/**").hasRole("MANAGER")
    .requestMatchers(HttpMethod.DELETE, "/api/products/**").hasRole("ADMIN")

    // 8. Catch-all — ALWAYS last
    .anyRequest().authenticated()

3.3 Method-Level Security

URL rules are coarse-grained. Method security gives per-method, per-object control — the real enterprise pattern.

java
// Enable on your config class (Chapter 3 config already has this)
// @EnableMethodSecurity(prePostEnabled = true, securedEnabled = true)

@RestController
@RequestMapping("/api/orders")
@RequiredArgsConstructor
public class OrderController {

    private final OrderService orderService;

    // 1. Basic role check
    @GetMapping
    @PreAuthorize("hasRole('USER')")
    public List<OrderDto> getMyOrders(
            @AuthenticationPrincipal CustomUserPrincipal principal) {
        return orderService.findByUser(principal.getUserId());
    }

    // 2. Admin sees all, user sees own
    @GetMapping("/{id}")
    @PreAuthorize("hasRole('ADMIN') or @orderSecurity.isOwner(#id, authentication)")
    public OrderDto getById(@PathVariable Long id) {
        return orderService.findById(id);
    }

    // 3. Authority-based (fine-grained permission)
    @PostMapping
    @PreAuthorize("hasAuthority('order:create')")
    public OrderDto create(@RequestBody @Valid CreateOrderRequest req,
                           @AuthenticationPrincipal CustomUserPrincipal principal) {
        return orderService.create(req, principal.getUserId());
    }

    // 4. PostAuthorize — check AFTER method returns
    // (useful when you need the return value to make the decision)
    @GetMapping("/invoice/{id}")
    @PostAuthorize("returnObject.userId == authentication.principal.userId")
    public InvoiceDto getInvoice(@PathVariable Long id) {
        return orderService.getInvoice(id);   // returns InvoiceDto with userId field
    }

    // 5. PreFilter — filter input collection before method runs
    @PutMapping("/bulk")
    @PreFilter("filterObject.userId == authentication.principal.userId")
    public List<OrderDto> bulkUpdate(@RequestBody List<UpdateOrderRequest> orders) {
        return orderService.bulkUpdate(orders);
    }

    // 6. PostFilter — filter output collection after method runs
    @GetMapping("/all")
    @PreAuthorize("hasRole('MANAGER')")
    @PostFilter("filterObject.tenantId == authentication.principal.tenantId")
    public List<OrderDto> getAllOrders() {
        return orderService.findAll();
    }

    // 7. @Secured — simpler, less flexible than @PreAuthorize
    @DeleteMapping("/{id}")
    @Secured({"ROLE_ADMIN"})
    public void delete(@PathVariable Long id) {
        orderService.delete(id);
    }
}

// Custom security bean for domain-object ownership checks
// Referenced in SpEL as @orderSecurity.isOwner(...)
@Component("orderSecurity")
@RequiredArgsConstructor
public class OrderSecurityService {

    private final OrderRepository orderRepository;

    public boolean isOwner(Long orderId, Authentication authentication) {
        if (authentication == null) return false;

        CustomUserPrincipal principal =
            (CustomUserPrincipal) authentication.getPrincipal();

        return orderRepository.findById(orderId)
            .map(order -> order.getUserId().equals(principal.getUserId()))
            .orElse(false);
    }

    // Tenant-level ownership — multi-tenant apps
    public boolean isSameTenant(Long resourceId, Authentication authentication) {
        CustomUserPrincipal principal =
            (CustomUserPrincipal) authentication.getPrincipal();

        return orderRepository.findById(resourceId)
            .map(order -> order.getTenantId().equals(principal.getTenantId()))
            .orElse(false);
    }
}

3.5 PermitAll vs Authenticated vs DenyAll
java
// Complete reference for access rules
.authorizeHttpRequests(auth -> auth

    // permitAll() — no authentication required, SecurityContext may be empty
    .requestMatchers("/public/**").permitAll()

    // anonymous() — only anonymous users (NOT logged-in users)
    // useful for: show login page only if not already logged in
    .requestMatchers("/login", "/register").anonymous()

    // fullyAuthenticated() — authenticated AND not via remember-me token
    // Use for sensitive operations like password change
    .requestMatchers("/change-password").fullyAuthenticated()

    // hasRole() — has specific role (prepends ROLE_ automatically)
    .requestMatchers("/admin").hasRole("ADMIN")

    // hasAuthority() — exact authority string match (no ROLE_ prepend)
    .requestMatchers("/reports/export").hasAuthority("report:export")

    // hasAnyRole() / hasAnyAuthority() — OR logic
    .requestMatchers("/dashboard").hasAnyRole("ADMIN", "MANAGER", "USER")

    // denyAll() — block everything (useful as safety catch-all during development)
    .requestMatchers("/internal/**").denyAll()

    // access() with custom AuthorizationManager — maximum flexibility
    .requestMatchers("/api/sensitive")
        .access((authentication, context) -> {
            boolean isAdmin = authentication.get().getAuthorities().stream()
                .anyMatch(a -> a.getAuthority().equals("ROLE_ADMIN"));
            String ip = context.getRequest().getRemoteAddr();
            boolean isInternalIp = ip.startsWith("10.") || ip.startsWith("192.168.");
            return new AuthorizationDecision(isAdmin && isInternalIp);
        })

    .anyRequest().authenticated()

// Pattern 2: Time-based access (e.g., maintenance window)
@Component
public class BusinessHoursAuthorizationManager
        implements AuthorizationManager<RequestAuthorizationContext> {

    @Override
    public AuthorizationDecision check(
            Supplier<Authentication> authentication,
            RequestAuthorizationContext context) {

        LocalTime now = LocalTime.now();
        LocalTime start = LocalTime.of(8, 0);
        LocalTime end   = LocalTime.of(20, 0);

        boolean withinHours = now.isAfter(start) && now.isBefore(end);
        boolean isAdmin = authentication.get().getAuthorities().stream()
            .anyMatch(a -> a.getAuthority().equals("ROLE_ADMIN"));

        // Admins bypass time restriction
        return new AuthorizationDecision(withinHours || isAdmin);
    }
}

@Component
@RequiredArgsConstructor
public class DynamicAuthorizationManager
        implements AuthorizationManager<RequestAuthorizationContext> {

    private final PermissionRepository permissionRepository;

    // Cache to avoid DB hit on every request
    @Cacheable("route-permissions")
    public Set<String> getRequiredRoles(String method, String path) {
        return permissionRepository
            .findByMethodAndPathPattern(method, path)
            .stream()
            .map(Permission::getRole)
            .collect(Collectors.toSet());
    }

    @Override
    public AuthorizationDecision check(
            Supplier<Authentication> authentication,
            RequestAuthorizationContext context) {

        HttpServletRequest req = context.getRequest();
        Set<String> required = getRequiredRoles(
            req.getMethod(),
            req.getRequestURI()
        );

        if (required.isEmpty()) return new AuthorizationDecision(true);

        Set<String> userRoles = authentication.get().getAuthorities()
            .stream()
            .map(GrantedAuthority::getAuthority)
            .collect(Collectors.toSet());

        boolean granted = required.stream().anyMatch(userRoles::contains);
        return new AuthorizationDecision(granted);
    }
}

// Custom AuthenticationSuccessHandler
// — redirect based on role, write audit log, set last-login timestamp
@Component
@RequiredArgsConstructor
@Slf4j
public class CustomAuthSuccessHandler
        implements AuthenticationSuccessHandler {

    private final UserRepository userRepository;
    private final AuditService auditService;

    @Override
    public void onAuthenticationSuccess(HttpServletRequest request,
                                        HttpServletResponse response,
                                        Authentication authentication)
            throws IOException {

        String username = authentication.getName();
        log.info("Login success: {}", username);

        // Update last login timestamp
        userRepository.updateLastLogin(username, Instant.now());

        // Write audit event
        auditService.record(AuditEvent.builder()
            .type("LOGIN_SUCCESS")
            .username(username)
            .ip(getClientIp(request))
            .userAgent(request.getHeader("User-Agent"))
            .build());

        // Role-based redirect
        String redirectUrl = determineRedirectUrl(authentication);
        new DefaultRedirectStrategy()
            .sendRedirect(request, response, redirectUrl);
    }

    private String determineRedirectUrl(Authentication auth) {
        Collection<? extends GrantedAuthority> authorities = auth.getAuthorities();

        if (hasRole(authorities, "ROLE_ADMIN"))   return "/admin/dashboard";
        if (hasRole(authorities, "ROLE_MANAGER")) return "/manager/dashboard";
        return "/user/dashboard";
    }

    private boolean hasRole(Collection<? extends GrantedAuthority> auths,
                            String role) {
        return auths.stream()
            .anyMatch(a -> a.getAuthority().equals(role));
    }

    private String getClientIp(HttpServletRequest request) {
        String forwarded = request.getHeader("X-Forwarded-For");
        return StringUtils.hasText(forwarded)
            ? forwarded.split(",")[0].trim()
            : request.getRemoteAddr();
    }
}

// Custom AuthenticationFailureHandler
// — track failed attempts, lock account after threshold
@Component
@RequiredArgsConstructor
@Slf4j
public class CustomAuthFailureHandler
        implements AuthenticationFailureHandler {

    private final LoginAttemptService loginAttemptService;
    private final AuditService auditService;
    private final ObjectMapper objectMapper;

    @Override
    public void onAuthenticationFailure(HttpServletRequest request,
                                        HttpServletResponse response,
                                        AuthenticationException ex)
            throws IOException {

        String username = request.getParameter("email");
        String ip       = request.getRemoteAddr();

        log.warn("Login failed for user: {} from IP: {}", username, ip);

        // Track and lock
        loginAttemptService.recordFailure(username, ip);

        // Audit
        auditService.record(AuditEvent.builder()
            .type("LOGIN_FAILURE")
            .username(username)
            .ip(ip)
            .reason(ex.getMessage())
            .build());

        // Respond — API clients get JSON, browsers get redirect
        String accept = request.getHeader(HttpHeaders.ACCEPT);
        if (accept != null && accept.contains(MediaType.APPLICATION_JSON_VALUE)) {
            response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
            response.setContentType(MediaType.APPLICATION_JSON_VALUE);
            objectMapper.writeValue(response.getOutputStream(), Map.of(
                "status",  401,
                "error",   "Authentication failed",
                "message", sanitizeMessage(ex),
                "locked",  loginAttemptService.isLocked(username)
            ));
        } else {
            String redirectUrl = loginAttemptService.isLocked(username)
                ? "/login?locked=true"
                : "/login?error=true";
            response.sendRedirect(redirectUrl);
        }
    }

    // Never expose internal exception messages to clients
    private String sanitizeMessage(AuthenticationException ex) {
        if (ex instanceof LockedException)          return "Account is locked";
        if (ex instanceof DisabledException)        return "Account is disabled";
        if (ex instanceof BadCredentialsException)  return "Invalid credentials";
        return "Authentication failed";
    }
}
java
// Login attempt tracking — brute force protection
@Service
@RequiredArgsConstructor
public class LoginAttemptService {

    private static final int MAX_ATTEMPTS = 5;
    private static final Duration LOCK_DURATION = Duration.ofMinutes(30);

    // Use Redis in production for distributed apps
    private final RedisTemplate<String, Integer> redisTemplate;

    public void recordFailure(String username, String ip) {
        String userKey = "login:fail:user:" + username;
        String ipKey   = "login:fail:ip:"   + ip;

        increment(userKey);
        increment(ipKey);
    }

    public void recordSuccess(String username) {
        // Clear on success
        redisTemplate.delete("login:fail:user:" + username);
    }

    public boolean isLocked(String username) {
        Integer attempts = redisTemplate.opsForValue()
            .get("login:fail:user:" + username);
        return attempts != null && attempts >= MAX_ATTEMPTS;
    }

    private void increment(String key) {
        redisTemplate.opsForValue().increment(key);
        redisTemplate.expire(key, LOCK_DURATION);
    }
}

// Session management — enterprise patterns
@Bean
public SecurityFilterChain sessionChain(HttpSecurity http) throws Exception {
    return http
        .sessionManagement(session -> session
            // Strategy: ALWAYS | IF_REQUIRED | NEVER | STATELESS
            .sessionCreationPolicy(SessionCreationPolicy.IF_REQUIRED)

            // Prevent session fixation attacks
            // CHANGE_SESSION_ID (default) — keeps attributes, issues new ID
            // NEW_SESSION — new session, copies only Spring Security attrs
            // MIGRATE_SESSION — new session ID, copies all attributes
            // NONE — no protection (never use in production)
            .sessionFixation(fix -> fix.changeSessionId())

            // Concurrent session control
            .maximumSessions(1)
                .maxSessionsPreventsLogin(false)     // kick old session (true = block new)
                .expiredSessionStrategy(customExpiredStrategy())
        )
        .build();
}

4.4 Custom Login & Logout — Full REST API Flow

// AuthController — the entry point for all auth operations
@RestController
@RequestMapping("/api/auth")
@RequiredArgsConstructor
@Slf4j
public class AuthController {

    private final AuthenticationManager authenticationManager;
    private final JwtService jwtService;
    private final UserService userService;
    private final RefreshTokenService refreshTokenService;
    private final LoginAttemptService loginAttemptService;

    // ── Login ─────────────────────────────────────────────────────────────
    @PostMapping("/login")
    public ResponseEntity<AuthResponse> login(
            @RequestBody @Valid LoginRequest request,
            HttpServletRequest httpRequest) {

        String ip = getClientIp(httpRequest);

        // Check brute-force lock before even attempting auth
        if (loginAttemptService.isLocked(request.getUsername())) {
            throw new AccountLockedException(
                "Account locked. Try again in 30 minutes.");
        }

        try {
            // Delegate to Spring Security's AuthenticationManager
            Authentication authentication = authenticationManager.authenticate(
                new UsernamePasswordAuthenticationToken(
                    request.getUsername(),
                    request.getPassword()
                )
            );

            // Auth succeeded — clear failure count
            loginAttemptService.recordSuccess(request.getUsername());

            CustomUserPrincipal principal =
                (CustomUserPrincipal) authentication.getPrincipal();

            // Generate tokens
            String accessToken  = jwtService.generateAccessToken(principal);
            String refreshToken = refreshTokenService.create(principal.getUserId());

            log.info("Login success: {} from {}", request.getUsername(), ip);

            return ResponseEntity.ok(AuthResponse.builder()
                .accessToken(accessToken)
                .refreshToken(refreshToken)
                .tokenType("Bearer")
                .expiresIn(jwtService.getAccessTokenExpiry())
                .userId(principal.getUserId())
                .username(principal.getUsername())
                .roles(principal.getAuthorities().stream()
                    .map(GrantedAuthority::getAuthority)
                    .collect(Collectors.toList()))
                .build());

        } catch (AuthenticationException ex) {
            loginAttemptService.recordFailure(request.getUsername(), ip);
            log.warn("Login failed: {} from {} — {}", request.getUsername(), ip,
                     ex.getMessage());
            // Sanitize — never reveal if username or password was wrong
            throw new BadCredentialsException("Invalid credentials");
        }
    }

    // ── Refresh Token ─────────────────────────────────────────────────────
    @PostMapping("/refresh")
    public ResponseEntity<AuthResponse> refresh(
            @RequestBody @Valid RefreshRequest request) {

        RefreshToken refreshToken = refreshTokenService
            .validateAndGet(request.getRefreshToken());

        CustomUserPrincipal principal =
            userService.loadPrincipalById(refreshToken.getUserId());

        String newAccessToken  = jwtService.generateAccessToken(principal);
        String newRefreshToken = refreshTokenService.rotate(refreshToken);

        return ResponseEntity.ok(AuthResponse.builder()
            .accessToken(newAccessToken)
            .refreshToken(newRefreshToken)
            .tokenType("Bearer")
            .expiresIn(jwtService.getAccessTokenExpiry())
            .build());
    }

    // ── Logout ────────────────────────────────────────────────────────────
    @PostMapping("/logout")
    public ResponseEntity<Void> logout(
            @RequestBody @Valid LogoutRequest request,
            @AuthenticationPrincipal CustomUserPrincipal principal) {

        // Revoke refresh token
        refreshTokenService.revoke(request.getRefreshToken());

        // Add access token to blacklist until expiry
        jwtService.blacklistToken(request.getAccessToken());

        log.info("Logout: {}", principal.getUsername());

        return ResponseEntity.noContent().build();
    }

    // ── Logout All Devices ────────────────────────────────────────────────
    @PostMapping("/logout-all")
    public ResponseEntity<Void> logoutAllDevices(
            @AuthenticationPrincipal CustomUserPrincipal principal) {

        refreshTokenService.revokeAllForUser(principal.getUserId());
        jwtService.blacklistAllTokensForUser(principal.getUserId());

        return ResponseEntity.noContent().build();
    }

    private String getClientIp(HttpServletRequest request) {
        String xff = request.getHeader("X-Forwarded-For");
        return StringUtils.hasText(xff)
            ? xff.split(",")[0].trim()
            : request.getRemoteAddr();
    }
}

// RefreshToken entity + service
@Entity
@Table(name = "refresh_tokens")
@Data @Builder
public class RefreshToken {

    @Id @GeneratedValue
    private Long id;

    @Column(nullable = false, unique = true)
    private String token;

    @Column(nullable = false)
    private Long userId;

    @Column(nullable = false)
    private Instant expiresAt;

    private boolean revoked;
}

@Service
@RequiredArgsConstructor
@Slf4j
public class RefreshTokenService {

    private final RefreshTokenRepository tokenRepository;

    @Value("${app.jwt.refresh-expiry:604800}")  // 7 days default
    private long refreshExpirySeconds;

    public String create(Long userId) {
        RefreshToken token = RefreshToken.builder()
            .token(UUID.randomUUID().toString())
            .userId(userId)
            .expiresAt(Instant.now().plusSeconds(refreshExpirySeconds))
            .revoked(false)
            .build();
        return tokenRepository.save(token).getToken();
    }

    public RefreshToken validateAndGet(String tokenValue) {
        RefreshToken token = tokenRepository.findByToken(tokenValue)
            .orElseThrow(() ->
                new InvalidTokenException("Refresh token not found"));

        if (token.isRevoked()) {
            // Token reuse detected — revoke ALL tokens for this user
            // (indicates refresh token theft)
            log.warn("Refresh token reuse detected for userId: {}",
                     token.getUserId());
            revokeAllForUser(token.getUserId());
            throw new InvalidTokenException("Refresh token reuse detected");
        }

        if (token.getExpiresAt().isBefore(Instant.now())) {
            throw new InvalidTokenException("Refresh token expired");
        }

        return token;
    }

    // Token rotation — one-time use tokens
    public String rotate(RefreshToken old) {
        old.setRevoked(true);
        tokenRepository.save(old);
        return create(old.getUserId());
    }

    public void revoke(String tokenValue) {
        tokenRepository.findByToken(tokenValue)
            .ifPresent(t -> {
                t.setRevoked(true);
                tokenRepository.save(t);
            });
    }

    public void revokeAllForUser(Long userId) {
        tokenRepository.revokeAllByUserId(userId);
    }
}

                .contentType(MediaType.APPLICATION_JSON)

                    """.formatted(auth.refreshToken())))
            .andExpect(status().isOk())
            .andExpect(jsonPath("$.accessToken").isNotEmpty())
            .andReturn();

        AuthResponse refreshed = objectMapper.readValue(
            refreshResult.getResponse().getContentAsString(), AuthResponse.class);

        // 4. Old refresh token is now invalid (token rotation)
        mockMvc.perform(post("/api/auth/refresh")
                .contentType(MediaType.APPLICATION_JSON)
                .content("""
                    {"refreshToken":"%s"}
                    """.formatted(auth.refreshToken())))
            .andExpect(status().isUnauthorized());

        // 5. Logout
        mockMvc.perform(post("/api/auth/logout")
                .header("Authorization", "Bearer " + refreshed.accessToken())
                .contentType(MediaType.APPLICATION_JSON)
                .content("""
                    {"accessToken":"%s","refreshToken":"%s"}
                    """.formatted(refreshed.accessToken(), refreshed.refreshToken())))
            .andExpect(status().isNoContent());

        // 6. Access token now invalid
        mockMvc.perform(get("/api/users/profile")
                .header("Authorization", "Bearer " + refreshed.accessToken()))
            .andExpect(status().isUnauthorized());
    }

@Service
@RequiredArgsConstructor
@Slf4j
public class EnterpriseUserDetailsService implements UserDetailsService {

    private final UserRepository userRepository;

    // Cache loaded user details — keyed by email
    @Cacheable(value = "userDetails", key = "#email",
               unless = "#result == null")
    @Override
    public UserDetails loadUserByUsername(String email)
            throws UsernameNotFoundException {

        log.debug("Loading UserDetails for: {}", email);

        User user = userRepository.findByEmailWithRoles(email)
            .orElseThrow(() -> {
                // Same message for "not found" and "wrong password"
                // prevents user enumeration
                log.warn("UserDetails not found for: {}", email);
                return new UsernameNotFoundException("Invalid credentials");
            });

        return buildPrincipal(user);
    }

    // Called by JwtAuthFilter to reload user by ID (from JWT claims)
    @Cacheable(value = "userDetailsById", key = "#userId")
    public UserDetails loadUserById(Long userId) {
        return userRepository.findById(userId)
            .map(this::buildPrincipal)
            .orElseThrow(() ->
                new UsernameNotFoundException("User not found: " + userId));
    }

    private CustomUserPrincipal buildPrincipal(User user) {
        return CustomUserPrincipal.builder()
            .userId(user.getId())
            .username(user.getEmail())
            .email(user.getEmail())
            .tenantId(user.getTenantId())
            .authorities(buildAuthorities(user))
            .enabled(user.isEnabled())
            .accountNonLocked(!user.isAccountLocked())
            .accountNonExpired(!user.isAccountExpired())
            .credentialsNonExpired(!user.isCredentialsExpired())
            .build();
    }

    private List<GrantedAuthority> buildAuthorities(User user) {
        return user.getRoles().stream()
            .flatMap(role -> {
                List<GrantedAuthority> auths = new ArrayList<>();
                // Add the role itself
                auths.add(new SimpleGrantedAuthority("ROLE_" + role.getName()));
                // Add all fine-grained permissions from this role
                role.getPermissions().stream()
                    .map(p -> new SimpleGrantedAuthority(p.getName()))
                    .forEach(auths::add);
                return auths.stream();
            })
            .distinct()
            .collect(Collectors.toList());
    }

    @CacheEvict(value = {"userDetails", "userDetailsById"},
                allEntries = true)
    public void evictCache() {
        log.info("User details cache evicted");
    }

    @CacheEvict(value = "userDetails", key = "#email")
    public void evictCacheForUser(String email) {
        log.info("Cache evicted for: {}", email);
    }
}

// RegistrationService — full lifecycle
@Service
@RequiredArgsConstructor
@Slf4j
@Transactional
public class RegistrationService {

    private final UserRepository         userRepository;
    private final RoleRepository         roleRepository;
    private final UserTokenRepository    tokenRepository;
    private final PasswordEncoder        passwordEncoder;
    private final EmailService           emailService;
    private final EnterpriseUserDetailsService userDetailsService;

    private static final Duration EMAIL_TOKEN_EXPIRY = Duration.ofHours(24);

    // ── Register ──────────────────────────────────────────────────────────
    public UserResponseDto register(RegisterRequest request) {

        // 1. Validate uniqueness
        if (userRepository.existsByEmail(request.email())) {
            throw new UserAlreadyExistsException(
                "Email already registered: " + request.email());
        }
        if (userRepository.existsByUsername(request.username())) {
            throw new UserAlreadyExistsException(
                "Username already taken: " + request.username());
        }

        // 2. Assign default role
        Role userRole = roleRepository.findByName("USER")
            .orElseThrow(() -> new IllegalStateException("Role USER not found"));

        // 3. Build and persist user
        User user = User.builder()
            .username(request.username())
            .email(request.email())
            .password(passwordEncoder.encode(request.password()))
            .firstName(request.firstName())
            .lastName(request.lastName())
            .tenantId(request.tenantId() != null
                       ? request.tenantId() : "default")
            .roles(Set.of(userRole))
            .enabled(true)
            .emailVerified(false)
            .build();

        User saved = userRepository.save(user);
        log.info("Registered user: {} (id={})", saved.getEmail(), saved.getId());

        // 4. Send verification email
        sendVerificationEmail(saved);

        return UserResponseDto.from(saved);
    }

    // ── Verify Email ──────────────────────────────────────────────────────
    public void verifyEmail(String token) {
        UserToken userToken = tokenRepository
            .findByTokenAndType(token, UserToken.TokenType.VERIFY_EMAIL)
            .orElseThrow(() ->
                new InvalidTokenException("Invalid verification token"));

        if (userToken.isUsed()) {
            throw new InvalidTokenException("Token already used");
        }
        if (userToken.isExpired()) {
            throw new InvalidTokenException("Verification token expired");
        }

        User user = userToken.getUser();
        user.setEmailVerified(true);
        userRepository.save(user);

        userToken.setUsed(true);
        tokenRepository.save(userToken);

        // Evict cache so next login loads fresh verified state
        userDetailsService.evictCacheForUser(user.getEmail());
        log.info("Email verified for: {}", user.getEmail());
    }

    // ── Resend Verification ───────────────────────────────────────────────
    public void resendVerification(String email) {
        User user = userRepository.findByEmail(email)
            .orElseThrow(() ->
                new UsernameNotFoundException("User not found"));

        if (user.isEmailVerified()) {
            throw new IllegalStateException("Email already verified");
        }

        // Invalidate old tokens
        tokenRepository.invalidateAllForUserAndType(
            user.getId(), UserToken.TokenType.VERIFY_EMAIL);

        sendVerificationEmail(user);
    }

    // ── Forgot Password ───────────────────────────────────────────────────
    public void forgotPassword(String email) {
        // Always return success — prevents user enumeration
        userRepository.findByEmail(email).ifPresent(user -> {
            tokenRepository.invalidateAllForUserAndType(
                user.getId(), UserToken.TokenType.RESET_PASSWORD);
            sendPasswordResetEmail(user);
        });
    }

    // ── Reset Password ────────────────────────────────────────────────────
    public void resetPassword(ResetPasswordRequest request) {
        UserToken userToken = tokenRepository
            .findByTokenAndType(request.token(),
                                UserToken.TokenType.RESET_PASSWORD)
            .orElseThrow(() ->
                new InvalidTokenException("Invalid reset token"));

        if (userToken.isUsed() || userToken.isExpired()) {
            throw new InvalidTokenException("Token is invalid or expired");
        }

        User user = userToken.getUser();
        user.setPassword(passwordEncoder.encode(request.newPassword()));
        user.setPasswordChangedAt(Instant.now());
        user.setCredentialsExpired(false);
        userRepository.save(user);

        userToken.setUsed(true);
        tokenRepository.save(userToken);

        // Force re-login everywhere
        userDetailsService.evictCacheForUser(user.getEmail());
        log.info("Password reset for: {}", user.getEmail());
    }

    // ── Private Helpers ───────────────────────────────────────────────────
    private void sendVerificationEmail(User user) {
        String token = generateAndSaveToken(
            user, UserToken.TokenType.VERIFY_EMAIL, EMAIL_TOKEN_EXPIRY);
        emailService.sendVerificationEmail(user.getEmail(), token);
    }

    private void sendPasswordResetEmail(User user) {
        String token = generateAndSaveToken(
            user, UserToken.TokenType.RESET_PASSWORD, Duration.ofHours(1));
        emailService.sendPasswordResetEmail(user.getEmail(), token);
    }

    private String generateAndSaveToken(User user,
                                        UserToken.TokenType type,
                                        Duration expiry) {
        String tokenValue = UUID.randomUUID().toString();
        tokenRepository.save(UserToken.builder()
            .user(user)
            .token(tokenValue)
            .type(type)
            .expiresAt(Instant.now().plus(expiry))
            .build());
        return tokenValue;
    }
}

public class AdminUserService {

    private final UserRepository     userRepository;
    private final RoleRepository     roleRepository;
    private final EnterpriseUserDetailsService userDetailsService;

    public Page<UserResponseDto> listUsers(Pageable pageable,
                                           String tenantId,
                                           String search) {
        // Dynamic query with Specifications
        Specification<User> spec = Specification.where(null);

        if (StringUtils.hasText(tenantId)) {
            spec = spec.and((root, q, cb) ->
                cb.equal(root.get("tenantId"), tenantId));
        }
        if (StringUtils.hasText(search)) {
            spec = spec.and((root, q, cb) -> cb.or(
                cb.like(cb.lower(root.get("email")),
                        "%" + search.toLowerCase() + "%"),
                cb.like(cb.lower(root.get("username")),
                        "%" + search.toLowerCase() + "%")
            ));
        }

        return userRepository.findAll(spec, pageable)
            .map(UserResponseDto::from);
    }

    public UserResponseDto findById(Long id) {
        return userRepository.findById(id)
            .map(UserResponseDto::from)
            .orElseThrow(() ->
                new UserNotFoundException("User not found: " + id));
    }

    public UserResponseDto updateRoles(Long userId, Set<String> roleNames) {
        User user = userRepository.findById(userId)
            .orElseThrow(() ->
                new UserNotFoundException("User not found: " + userId));

        Set<Role> roles = new HashSet<>(roleRepository.findByNameIn(roleNames));
        if (roles.size() != roleNames.size()) {
            throw new IllegalArgumentException("One or more roles not found");
        }

        user.setRoles(roles);
        User saved = userRepository.save(user);

        userDetailsService.evictCacheForUser(user.getEmail());
        log.info("Roles updated for user {}: {}", userId, roleNames);

        return UserResponseDto.from(saved);
    }

    public void setEnabled(Long userId, boolean enabled) {
        User user = getUser(userId);
        user.setEnabled(enabled);
        userRepository.save(user);
        userDetailsService.evictCacheForUser(user.getEmail());
        log.info("User {} {}", userId, enabled ? "enabled" : "disabled");
    }

    public void setLocked(Long userId, boolean locked) {
        User user = getUser(userId);
        user.setAccountLocked(locked);
        if (!locked) user.setFailedAttempts(0);   // reset on unlock
        userRepository.save(user);
        userDetailsService.evictCacheForUser(user.getEmail());
        log.info("User {} {}", userId, locked ? "locked" : "unlocked");
    }

    public void expireCredentials(Long userId) {
        User user = getUser(userId);
        user.setCredentialsExpired(true);
        userRepository.save(user);
        userDetailsService.evictCacheForUser(user.getEmail());
    }

    public void delete(Long userId) {
        User user = getUser(userId);
        userRepository.delete(user);
        userDetailsService.evictCacheForUser(user.getEmail());
        log.info("User deleted: {}", userId);
    }

    private User getUser(Long id) {
        return userRepository.findById(id)
            .orElseThrow(() ->
                new UserNotFoundException("User not found: " + id));
    }
}

    }

15.2 OncePerRequestFilter — The Right Base Class
java
// Always extend OncePerRequestFilter for custom security filters
// Guarantees doFilterInternal is called EXACTLY ONCE per request
// even when RequestDispatcher.forward() or include() is used

@Component
@Slf4j
public class RequestLoggingFilter extends OncePerRequestFilter {

    // ── Skip logic — declarative ───────────────────────────────────────────
    @Override
    protected boolean shouldNotFilter(HttpServletRequest request) {
        String path = request.getServletPath();

        // Skip static resources and health checks — no logging needed
        return path.startsWith("/actuator/") ||
               path.startsWith("/static/")   ||
               path.startsWith("/favicon")   ||
               path.endsWith(".css")         ||
               path.endsWith(".js")          ||
               path.endsWith(".png");
    }

    // ── Main logic ─────────────────────────────────────────────────────────
    @Override
    protected void doFilterInternal(HttpServletRequest  request,
                                    HttpServletResponse response,
                                    FilterChain         chain)
            throws ServletException, IOException {

        long start = System.currentTimeMillis();
        String requestId = UUID.randomUUID().toString();

        // Attach requestId to MDC for log correlation
        MDC.put("requestId", requestId);
        MDC.put("method",    request.getMethod());
        MDC.put("path",      request.getServletPath());

        // Add requestId to response header so clients can trace
        response.setHeader("X-Request-Id", requestId);

        try {
            log.info("→ {} {} [{}]",
                request.getMethod(),
                request.getRequestURI(),
                request.getRemoteAddr());

            chain.doFilter(request, response);   // continue chain

            log.info("← {} {} {}ms status={}",
                request.getMethod(),
                request.getRequestURI(),
                System.currentTimeMillis() - start,
                response.getStatus());

        } finally {
            MDC.clear();   // CRITICAL — always clear MDC on same thread
        }
    }
}

Filter 1 — Tenant Context Filter
java
// Extracts tenant from subdomain or header, stores in thread-local
// Runs AFTER JwtAuthFilter so tenantId is already in SecurityContext
@Component
@RequiredArgsConstructor
@Slf4j
public class TenantContextFilter extends OncePerRequestFilter {

    private final TenantRepository tenantRepository;

    @Override
    protected void doFilterInternal(HttpServletRequest  request,
                                    HttpServletResponse response,
                                    FilterChain         chain)
            throws ServletException, IOException {

        String tenantId = resolveTenantId(request);

        if (tenantId != null) {
            // Validate tenant exists and is active
            boolean valid = tenantRepository.existsByIdAndActive(tenantId, true);
            if (!valid) {
                response.setStatus(HttpServletResponse.SC_FORBIDDEN);
                response.setContentType(MediaType.APPLICATION_JSON_VALUE);
                response.getWriter().write("""
                    {"status":403,"error":"Invalid or inactive tenant"}
                    """);
                return;
            }
            TenantContext.setTenantId(tenantId);
        }

        try {
            chain.doFilter(request, response);
        } finally {
            TenantContext.clear();   // CRITICAL — clear thread-local after request
        }
    }

    private String resolveTenantId(HttpServletRequest request) {
        // Strategy 1: from JWT principal (most reliable)
        Authentication auth = SecurityContextHolder.getContext()
            .getAuthentication();
        if (auth != null && auth.getPrincipal()
                instanceof CustomUserPrincipal p) {
            return p.getTenantId();
        }

        // Strategy 2: from X-Tenant-Id header (gateway-injected)
        String header = request.getHeader("X-Tenant-Id");
        if (StringUtils.hasText(header)) return header;

        // Strategy 3: from subdomain (tenant.yourapp.com)
        String host = request.getServerName();
        if (host.contains(".yourapp.com")) {
            String subdomain = host.split("\\.")[0];
            if (!"www".equals(subdomain) && !"api".equals(subdomain)) {
                return subdomain;
            }
        }

        return null;
    }
}

Filter 2 — API Key Authentication Filter
java
// Accepts API key in header alongside OR instead of JWT
// Useful for machine clients, webhooks, partner integrations
@Component
@RequiredArgsConstructor
@Slf4j
public class ApiKeyAuthenticationFilter extends OncePerRequestFilter {

    private static final String API_KEY_HEADER = "X-Api-Key";

    private final ApiKeyService   apiKeyService;
    private final RateLimitService rateLimitService;

    @Override
    protected boolean shouldNotFilter(HttpServletRequest request) {
        // Only process if API key header is present
        // If absent, fall through to JWT filter
        return !StringUtils.hasText(request.getHeader(API_KEY_HEADER));
    }

    @Override
    protected void doFilterInternal(HttpServletRequest  request,
                                    HttpServletResponse response,
                                    FilterChain         chain)
            throws ServletException, IOException {

        String apiKey = request.getHeader(API_KEY_HEADER);

        // Rate-limit by API key BEFORE any DB lookup
        if (rateLimitService.isRateLimited(apiKey)) {
            sendError(response, 429,
                "RATE_LIMITED", "API key rate limit exceeded");
            return;
        }

        apiKeyService.findByKey(apiKey)
            .filter(ApiKeyEntity::isActive)
            .filter(k -> !k.isExpired())
            .ifPresentOrElse(
                key -> {
                    // Valid key — build authentication
                    List<GrantedAuthority> authorities = key.getScopes()
                        .stream()
                        .map(SimpleGrantedAuthority::new)
                        .collect(Collectors.toList());

                    UsernamePasswordAuthenticationToken auth =
                        new UsernamePasswordAuthenticationToken(
                            key.getClientId(),
                            null,
                            authorities
                        );
                    auth.setDetails(
                        new WebAuthenticationDetailsSource()
                            .buildDetails(request));

                    SecurityContextHolder.getContext()
                        .setAuthentication(auth);

                    // Track API key usage asynchronously
                    apiKeyService.recordUsageAsync(key.getId(),
                        request.getRemoteAddr());

                    log.debug("API key auth: client={}",
                        key.getClientId());
                },
                () -> {
                    // Invalid key — reject immediately
                    SecurityContextHolder.clearContext();
                    try {
                        sendError(response, 401,
                            "INVALID_API_KEY", "Invalid or expired API key");
                    } catch (IOException e) {
                        throw new RuntimeException(e);
                    }
                    return;
                }
            );

        // Only continue if authentication was set
        if (SecurityContextHolder.getContext().getAuthentication() != null) {
            chain.doFilter(request, response);
        }
    }

    private void sendError(HttpServletResponse response,
                           int status, String code, String message)
            throws IOException {
        response.setStatus(status);
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        response.getWriter().write("""
            {"status":%d,"code":"%s","message":"%s","timestamp":"%s"}
            """.formatted(status, code, message, Instant.now()));
    }
}
Filter 3 — Request Validation Filter
java
// Sanitize and validate every request before it reaches controllers
// Defence-in-depth against injection attacks, oversized payloads
@Component
@RequiredArgsConstructor
@Slf4j
public class RequestValidationFilter extends OncePerRequestFilter {

    private static final int    MAX_HEADER_SIZE    = 8_192;    // 8 KB
    private static final int    MAX_PARAM_LENGTH   = 2_048;
    private static final int    MAX_URI_LENGTH     = 2_048;
    private static final Set<String> BLOCKED_HEADERS = Set.of(
        "X-Forwarded-Host",     // can be used for host header injection
        "X-Original-URL",
        "X-Rewrite-URL"
    );

    @Override
    protected void doFilterInternal(HttpServletRequest  request,
                                    HttpServletResponse response,
                                    FilterChain         chain)
            throws ServletException, IOException {

        // 1. URI length check
        if (request.getRequestURI().length() > MAX_URI_LENGTH) {
            log.warn("URI too long: {} chars from {}",
                request.getRequestURI().length(),
                request.getRemoteAddr());
            sendError(response, 414, "URI_TOO_LONG",
                "Request URI too long");
            return;
        }

        // 2. Blocked headers
        for (String blocked : BLOCKED_HEADERS) {
            if (request.getHeader(blocked) != null) {
                log.warn("Blocked header present: {} from {}",
                    blocked, request.getRemoteAddr());
                sendError(response, 400, "INVALID_HEADER",
                    "Invalid request header");
                return;
            }
        }

        // 3. Header size check
        long totalHeaderSize = Collections.list(request.getHeaderNames())
            .stream()
            .mapToLong(name ->
                name.length() +
                request.getHeader(name).length())
            .sum();

        if (totalHeaderSize > MAX_HEADER_SIZE) {
            sendError(response, 431, "HEADERS_TOO_LARGE",
                "Request headers too large");
            return;
        }

        // 4. Query parameter length check
        if (request.getQueryString() != null &&
            request.getQueryString().length() > MAX_PARAM_LENGTH) {
            sendError(response, 400, "PARAMS_TOO_LONG",
                "Query string too long");
            return;
        }

        // 5. Path traversal check
        String uri = request.getRequestURI();
        if (uri.contains("../") || uri.contains("..\\") ||
            uri.contains("%2e%2e") || uri.contains("%2E%2E")) {
            log.warn("Path traversal attempt: {} from {}",
                uri, request.getRemoteAddr());
            sendError(response, 400, "INVALID_PATH",
                "Invalid request path");
            return;
        }

        chain.doFilter(request, response);
    }

    private void sendError(HttpServletResponse response,
                           int status, String code, String message)
            throws IOException {
        response.setStatus(status);
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        response.getWriter().write("""
            {"status":%d,"code":"%s","message":"%s"}
            """.formatted(status, code, message));
    }
}

15.4 JWT Authentication Filter — Production Grade
java
// The most important custom filter in any JWT-based application
// This is the complete, production-hardened implementation

@Component
@RequiredArgsConstructor
@Slf4j
public class JwtAuthenticationFilter extends OncePerRequestFilter {

    private final JwtService            jwtService;
    private final TokenBlacklistService blacklistService;
    private final UserRepository        userRepository;
    private final MeterRegistry         meterRegistry;   // Micrometer metrics

    // Counters for observability
    private Counter authSuccessCounter;
    private Counter authFailureCounter;
    private Counter tokenExpiredCounter;

    @PostConstruct
    public void initMetrics() {
        authSuccessCounter = Counter.builder("jwt.auth.success")
            .description("Successful JWT authentications")
            .register(meterRegistry);
        authFailureCounter = Counter.builder("jwt.auth.failure")
            .description("Failed JWT authentications")
            .register(meterRegistry);
        tokenExpiredCounter = Counter.builder("jwt.auth.expired")
            .description("Expired JWT tokens")
            .register(meterRegistry);
    }

    // ── Skip paths — never authenticate these ─────────────────────────────
    private static final Set<String> SKIP_EXACT = Set.of(
        "/api/auth/login",
        "/api/auth/register",
        "/api/auth/refresh",
        "/api/auth/forgot-password",
        "/api/auth/verify-email",
        "/actuator/health",
        "/actuator/info",
        "/.well-known/jwks.json"
    );

    private static final Set<String> SKIP_PREFIXES = Set.of(
        "/api/public/",
        "/api/auth/reset-password",
        "/static/",
        "/swagger-ui",
        "/v3/api-docs"
    );

    @Override
    protected boolean shouldNotFilter(HttpServletRequest request) {
        String path = request.getServletPath();
        return SKIP_EXACT.contains(path) ||
               SKIP_PREFIXES.stream().anyMatch(path::startsWith) ||
               HttpMethod.OPTIONS.name().equals(request.getMethod());
    }

    // ── Core filter logic ──────────────────────────────────────────────────
    @Override
    protected void doFilterInternal(HttpServletRequest  request,
                                    HttpServletResponse response,
                                    FilterChain         chain)
            throws ServletException, IOException {

        // 1. Extract token from request
        String token = extractToken(request);

        if (!StringUtils.hasText(token)) {
            // No token — let the request through
            // AuthorizationFilter will handle unauthenticated endpoints
            chain.doFilter(request, response);
            return;
        }

        // 2. Process token
        try {
            processToken(token, request);
            authSuccessCounter.increment();
            chain.doFilter(request, response);

        } catch (TokenExpiredException ex) {
            tokenExpiredCounter.increment();
            log.debug("Expired token path={}", request.getServletPath());
            sendTokenError(response, "TOKEN_EXPIRED",
                "Access token has expired", HttpStatus.UNAUTHORIZED);

        } catch (InvalidTokenException ex) {
            authFailureCounter.increment();
            log.warn("Invalid token path={} reason={}",
                request.getServletPath(), ex.getMessage());
            sendTokenError(response, "INVALID_TOKEN",
                "Token is invalid or has been revoked",
                HttpStatus.UNAUTHORIZED);

        } catch (DisabledException | LockedException ex) {
            authFailureCounter.increment();
            log.warn("Account issue: {} path={}",
                ex.getMessage(), request.getServletPath());
            sendTokenError(response, "ACCOUNT_ISSUE",
                ex.getMessage(), HttpStatus.FORBIDDEN);

        } catch (Exception ex) {
            authFailureCounter.increment();
            log.error("JWT filter unexpected error path={}: {}",
                request.getServletPath(), ex.getMessage(), ex);
            sendTokenError(response, "AUTH_ERROR",
                "Authentication processing failed",
                HttpStatus.INTERNAL_SERVER_ERROR);
        }
    }

    // ── Token processing pipeline ──────────────────────────────────────────
    private void processToken(String token, HttpServletRequest request) {

        // Step 1: Validate signature, expiry, issuer, audience
        Claims claims = jwtService.validateAndExtractClaims(token);

        // Step 2: Verify token type = ACCESS (not REFRESH)
        String tokenType = claims.get("type", String.class);
        if (!"ACCESS".equals(tokenType)) {
            throw new InvalidTokenException(
                "Token type mismatch: expected ACCESS, got " + tokenType);
        }

        // Step 3: Check Redis blacklist — revoked tokens
        String jti = claims.getId();
        if (jti == null) {
            throw new InvalidTokenException("Token missing jti claim");
        }
        if (blacklistService.isBlacklisted(jti)) {
            throw new InvalidTokenException("Token has been revoked");
        }

        // Step 4: Token version check — invalidates all tokens on
        // password change / security event (optional — costs 1 DB read)
        if (isTokenVersionCheckEnabled()) {
            verifyTokenVersion(claims);
        }

        // Step 5: Build SecurityContext (no DB read — from JWT claims)
        CustomUserPrincipal principal = buildPrincipalFromClaims(claims);
        List<GrantedAuthority> authorities =
            jwtService.extractAuthorities(token);

        UsernamePasswordAuthenticationToken authentication =
            new UsernamePasswordAuthenticationToken(
                principal,
                null,          // credentials null after validation
                authorities
            );

        // Attach request details for audit logging
        authentication.setDetails(
            new WebAuthenticationDetailsSource().buildDetails(request));

        SecurityContextHolder.getContext()
            .setAuthentication(authentication);

        // Enrich MDC for structured logging
        MDC.put("userId",   String.valueOf(principal.getUserId()));
        MDC.put("tenantId", principal.getTenantId());
        MDC.put("jti",      jti);
    }

    // ── Token extraction strategies ────────────────────────────────────────
    private String extractToken(HttpServletRequest request) {

        // Strategy 1: Authorization: Bearer <token> (primary — REST APIs)
        String authHeader = request.getHeader(HttpHeaders.AUTHORIZATION);
        if (StringUtils.hasText(authHeader) &&
            authHeader.startsWith("Bearer ")) {
            String token = authHeader.substring(7).trim();
            if (StringUtils.hasText(token)) return token;
        }

        // Strategy 2: X-Auth-Token header (legacy support)
        String xAuthToken = request.getHeader("X-Auth-Token");
        if (StringUtils.hasText(xAuthToken)) return xAuthToken;

        // Strategy 3: Cookie (HttpOnly cookie for browser apps)
        // ONLY if CSRF protection is also enabled
        if (isCookieAuthEnabled()) {
            Cookie[] cookies = request.getCookies();
            if (cookies != null) {
                return Arrays.stream(cookies)
                    .filter(c -> "access_token".equals(c.getName()))
                    .map(Cookie::getValue)
                    .filter(StringUtils::hasText)
                    .findFirst()
                    .orElse(null);
            }
        }

        // Strategy 4: Query param (NEVER for production APIs)
        // Only for WebSocket handshakes where headers aren't available
        if (isWebSocketHandshake(request)) {
            String tokenParam = request.getParameter("token");
            if (StringUtils.hasText(tokenParam)) return tokenParam;
        }

        return null;
    }

    // ── Build principal from JWT claims — zero DB calls ───────────────────
    private CustomUserPrincipal buildPrincipalFromClaims(Claims claims) {
        Long   userId   = Long.valueOf(claims.getSubject());
        String email    = claims.get("email",    String.class);
        String username = claims.get("username", String.class);
        String tenantId = claims.get("tenantId", String.class);

        return CustomUserPrincipal.builder()
            .userId(userId)
            .email(email)
            .username(username != null ? username : email)
            .tenantId(tenantId != null ? tenantId : "default")
            .build();
    }

    // ── Optional: token version check ─────────────────────────────────────
    // Enables immediate invalidation of all tokens without Redis
    // Trade-off: 1 DB read per request vs instant revocation
    private void verifyTokenVersion(Claims claims) {
        Integer tokenVersion = claims.get("tokenVersion", Integer.class);
        if (tokenVersion == null) return;

        Long userId = Long.valueOf(claims.getSubject());

        // Cache this check to reduce DB load
        int dbVersion = userRepository.getTokenVersion(userId);
        if (tokenVersion < dbVersion) {
            throw new InvalidTokenException(
                "Token invalidated by security event");
        }
    }

    @Value("${app.jwt.token-version-check-enabled:false}")
    private boolean tokenVersionCheckEnabled;

    @Value("${app.jwt.cookie-auth-enabled:false}")
    private boolean cookieAuthEnabled;

    private boolean isTokenVersionCheckEnabled() {
        return tokenVersionCheckEnabled;
    }

    private boolean isCookieAuthEnabled() {
        return cookieAuthEnabled;
    }

    private boolean isWebSocketHandshake(HttpServletRequest request) {
        String upgrade = request.getHeader("Upgrade");
        return "websocket".equalsIgnoreCase(upgrade);
    }

    // ── Error response ─────────────────────────────────────────────────────
    private void sendTokenError(HttpServletResponse response,
                                 String code,
                                 String message,
                                 HttpStatus status) throws IOException {
        // Clear any partial SecurityContext
        SecurityContextHolder.clearContext();

        response.setStatus(status.value());
        response.setContentType(MediaType.APPLICATION_JSON_VALUE);
        response.setCharacterEncoding("UTF-8");

        // Never include internal details in error response
        String body = """
            {
              "status": %d,
              "code": "%s",
              "message": "%s",
              "timestamp": "%s",
              "requestId": "%s"
            }
            """.formatted(
                status.value(),
                code,
                message,
                Instant.now(),
                MDC.get("requestId") != null
                    ? MDC.get("requestId")
                    : UUID.randomUUID().toString()
            );

        response.getWriter().write(body);
        response.getWriter().flush();
    }
}
15.5 Wiring All Filters Into Security Config
java
@Configuration
@EnableWebSecurity
@EnableMethodSecurity
@RequiredArgsConstructor
public class SecurityConfig {

    // Custom filters
    private final JwtAuthenticationFilter    jwtFilter;
    private final ApiKeyAuthenticationFilter apiKeyFilter;
    private final RequestLoggingFilter       loggingFilter;
    private final RequestValidationFilter    validationFilter;
    private final TenantContextFilter        tenantFilter;
    private final SecurityResponseHeadersFilter headersFilter;

    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http)
            throws Exception {
        return http
            .csrf(csrf -> csrf.disable())
            .sessionManagement(s -> s
                .sessionCreationPolicy(SessionCreationPolicy.STATELESS))
            .cors(cors -> cors.configurationSource(corsSource()))
            .authorizeHttpRequests(auth -> auth
                .requestMatchers(HttpMethod.OPTIONS, "/**").permitAll()
                .requestMatchers("/api/auth/**", "/api/public/**",
                                 "/actuator/health").permitAll()
                .requestMatchers("/api/admin/**").hasRole("ADMIN")
                .anyRequest().authenticated()
            )

            // ── Filter ordering ──────────────────────────────────────────
            // 1. Validation first — reject malformed requests early
            .addFilterBefore(validationFilter,
                SecurityContextHolderFilter.class)

            // 2. Logging — wraps everything after validation
            .addFilterAfter(loggingFilter,
                validationFilter.getClass())

            // 3. API Key auth — before JWT
            .addFilterBefore(apiKeyFilter,
                UsernamePasswordAuthenticationFilter.class)

            // 4. JWT auth — core auth filter
            .addFilterBefore(jwtFilter,
                UsernamePasswordAuthenticationFilter.class)

            // 5. Tenant context — after auth so principal is available
            .addFilterAfter(tenantFilter,
                jwtFilter.getClass())

            // 6. Security response headers — wraps everything
            .addFilterAfter(headersFilter,
                TenantContextFilter.class)

            .exceptionHandling(ex -> ex
                .authenticationEntryPoint(authEntryPoint())
                .accessDeniedHandler(accessDeniedHandler())
            )
            .build();
    }
}

Chapter 15 — Quick Reference
Filter placement guide
──────────────────────────────────────────────────────────────
addFilterBefore(myFilter, SecurityContextHolderFilter.class)
    → Runs before security context is loaded
    → Use for: request validation, rate limiting

addFilterBefore(myFilter, UsernamePasswordAuthenticationFilter.class)
    → Standard position for custom auth filters (JWT, API key)
    → Use for: JwtAuthFilter, ApiKeyFilter, OAuth token filters

addFilterAfter(myFilter, UsernamePasswordAuthenticationFilter.class)
    → Runs after auth attempt
    → Use for: tenant context, MFA check, audit enrichment

addFilterAfter(myFilter, AuthorizationFilter.class)
    → Runs after authorization check passes
    → Use for: response headers, response logging

OncePerRequestFilter contract
──────────────────────────────────────────────────────────────
✓  Override shouldNotFilter()  for skip logic
✓  Override doFilterInternal() for main logic
✓  Always call chain.doFilter() OR write response (never both)
✓  Always clear ThreadLocal in finally block
✓  Never throw exceptions — catch and write error response

JwtAuthFilter pipeline
──────────────────────────────────────────────────────────────
1. Extract token  (Bearer header → X-Auth-Token → Cookie)
2. Validate claims (signature, expiry, issuer, audience)
3. Verify type = ACCESS (not REFRESH)
4. Check blacklist (Redis jti lookup)
5. Verify token version (optional — 1 DB read)
6. Build principal from claims (zero DB reads)
7. Set SecurityContext
8. Enrich MDC (userId, tenantId, jti)

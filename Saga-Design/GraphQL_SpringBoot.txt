1️⃣ What is GraphQL?
GraphQL is a query language for APIs that allows clients to request only the data they need.

REST Example
GET /products/1
Response

{
 id:1,
 name:"Laptop",
 price:70000,
 description:"Gaming Laptop",
 category:"Electronics"
}
But if the client needs only name, REST still returns everything.

GraphQL Example
Query

query {
 productById(id:1){
  name
 }
}
Response

{
 "data":{
   "productById":{
      "name":"Laptop"
   }
 }
}

✔ Only requested data returned.

9️⃣ GraphQL Controller (Resolver)
package com.example.controller;

import java.util.List;

import org.springframework.graphql.data.method.annotation.QueryMapping;
import org.springframework.graphql.data.method.annotation.MutationMapping;
import org.springframework.graphql.data.method.annotation.Argument;
import org.springframework.stereotype.Controller;

import com.example.entity.Product;
import com.example.service.ProductService;

@Controller
public class ProductController {

 private final ProductService service;

 public ProductController(ProductService service) {
     this.service = service;
 }

 // Query -> get all products
 @QueryMapping
 public List<Product> products() {
     return service.getProducts();
 }

 // Query -> get product by id
 @QueryMapping
 public Product productById(@Argument Long id) {
     return service.getProductById(id);
 }

 // Mutation -> create product
 @MutationMapping
 public Product createProduct(
     @Argument String name,
     @Argument double price,
     @Argument String category) {

     Product product = new Product();
     product.setName(name);
     product.setPrice(price);
     product.setCategory(category);

     return service.saveProduct(product);
 }
}
Important annotations

@QueryMapping → GraphQL Query
@MutationMapping → GraphQL Mutation
@Argument → input parameter

2️⃣ GraphQL DataLoader (Solving N+1 Query Problem)
Problem

If we have 100 students:

GraphQL execution:

1 query → get students
100 queries → get courses
Total queries = 101

This is called N+1 problem.

Solution: DataLoader
DataLoader batches queries.

Instead of

getCourses(1)
getCourses(2)
getCourses(3)
It sends

SELECT * FROM course WHERE student_id IN (1,2,3)
Hands-On Implementation

Step 1 Dependency
Already included in Spring GraphQL.

Step 2 Create DataLoader

@Component
public class CourseBatchLoader
      implements BatchLoader<Long,List<Course>> {

 @Autowired
 CourseRepository repo;

 @Override
 public CompletionStage<List<List<Course>>> load(List<Long> studentIds){

   List<Course> courses = repo.findByStudentIdIn(studentIds);

   Map<Long,List<Course>> map = courses.stream()
      .collect(Collectors.groupingBy(Course::getStudentId));

   List<List<Course>> result = studentIds.stream()
       .map(id -> map.getOrDefault(id,List.of()))
       .toList();

   return CompletableFuture.completedFuture(result);
 }
}

Step 3 Use DataLoader in Resolver
@SchemaMapping(typeName="Student", field="courses")
public CompletableFuture<List<Course>> courses(
       Student student,
       DataLoader<Long,List<Course>> loader){

 return loader.load(student.getId());
}

Now execution becomes:

students()

DataLoader batch query

SELECT * FROM course WHERE student_id IN (1..100)
✔ Performance improved.

@Component
public class JwtFilter extends OncePerRequestFilter {

 protected void doFilterInternal(...){

   String token = request.getHeader("Authorization");

   if(token != null){
      String username = jwtUtil.extractUsername(token);
      SecurityContextHolder.getContext()
         .setAuthentication(
           new UsernamePasswordAuthenticationToken(username,null,List.of())
         );
   }

   filterChain.doFilter(request,response);
 }
}

8️⃣ Query Resolver

@Controller
public class UserResolver {

 @Autowired
 WebClient userClient;

 @QueryMapping
 public List<User> users(){

  return userClient.get()
        .uri("/users")
        .retrieve()
        .bodyToFlux(User.class)
        .collectList()
        .block();
 }
}

9️⃣ User → Orders Resolver

@SchemaMapping(typeName="User",field="orders")
public List<Order> orders(User user){

 return orderClient.get()
      .uri("/orders/user/"+user.getId())
      .retrieve()
      .bodyToFlux(Order.class)
      .collectList()
      .block();
}

🔟 Order → Product Resolver

@SchemaMapping(typeName="Order",field="product")
public Product product(Order order){

 return productClient.get()
      .uri("/products/"+order.getProductId())
      .retrieve()
      .bodyToMono(Product.class)
      .block();
}
